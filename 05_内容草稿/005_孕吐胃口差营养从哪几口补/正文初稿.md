# 孕吐胃口差，营养从哪几口补？

🤰怀孕后，饭吃几口就放下了，又惦记着营养跟不跟得上。胃口这么小，到底先吃什么？

先把每次的量减小，搭配抓住两件事：饭、面这些主食带上蛋或豆腐，奶和水果留到两餐之间。

👇从软面、拌饭到奶果加餐，下面三组搭配，讲清这几口分别能补进什么营养。

**🍜 想吃软和的：清汤面 + 鸡蛋 + 碎青菜**

**关键词：补充能量、蛋白质、蔬菜搭配**

面条提供能量，鸡蛋补充蛋白质，青菜添上维生素和膳食纤维。蛋味让你反胃，就换成几块嫩豆腐。

**🍅 想吃点酸香的：番茄炖豆腐 + 米饭**

**关键词：植物蛋白、软嫩、带汁拌饭**

肉味让你反胃时，豆腐可以提供植物蛋白，给这一餐补上主食之外的蛋白质来源。番茄炒软出汁，加嫩豆腐炖熟，连着汁拌饭，口感软嫩，也吃到了一份蔬菜。

能接受鸡蛋的话，也可以用番茄炒蛋拌饭。酸味按自己的胃口来，吃着反胃就换清淡的，不必勉强。

**🥛 两餐之间：原味酸奶 + 香蕉片**

**关键词：钙、蛋白质、膳食纤维**

酸奶提供钙和蛋白质，香蕉提供碳水化合物和膳食纤维，两样搭配，给加餐添上不同的营养来源。不喜欢酸奶的酸味，可以换成牛奶，香蕉分开吃。

💡这几份搭配提供的是不同营养来源，吃几口还不能代表一天已经补够。胃口好些时，逐渐增加分量，添回肉鱼和不同的蔬菜，让饮食种类更丰富。
