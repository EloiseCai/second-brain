## 02 南瓜小米粥｜先从软烂的主食吃起

食材（一次制作的用量，不是每日摄入目标）：小米30克、去皮南瓜80克、水约400毫升。

1. 小米淘洗，南瓜切小丁。
2. 水开后下小米，转小火煮约15分钟。
3. 加入南瓜，再煮10—15分钟，煮到米粒软、南瓜能压散。
4. 先盛小半碗，舀着米粒和南瓜一起吃。

营养与搭配：小米提供碳水化合物，南瓜带来甜味，不额外加糖。胃口好一些时，再搭几口蛋或豆腐。

怎么少量吃：先盛少量，吃得下再添；这碗粥不代替全天其他食物。

## 03 鸡蛋青菜面｜几口面，也带上蛋和菜

食材（一次制作的用量，不是每日摄入目标）：细面30克、鸡蛋1个、青菜30克、水约350毫升。

1. 青菜洗净切小段，鸡蛋打散。
2. 水开下面条，煮至接近软熟。
3. 加入青菜，缓缓倒入蛋液，煮到蛋花完全凝固、面菜熟透。
4. 少盛汤，先夹几口面，再吃蛋花和青菜。

营养与搭配：面条提供碳水化合物，鸡蛋提供蛋白质，青菜增加蔬菜种类。一碗里搭配好，分几次少量吃。

怎么少量吃：不先煎蛋、不加辣油；若热气味让你难受，盛出稍晾至适口再吃。

制作依据：B25第10张。保持上半部两张成品近景，下半部食材与步骤小图的组织关系；原图的3次成品展示减为2次，腾出约2行营养说明。步骤缩为4格，保留原图清晰的食物与做法主线，不换其他笔记模板。

## 04 番茄炒蛋｜想吃带点酸味的，试这几口

食材（一次制作的用量，不是每日摄入目标）：番茄1个、鸡蛋1个、食用油半茶匙、少量盐。

1. 番茄洗净切小块，鸡蛋打散。
2. 不粘锅放少量油，下蛋液炒到完全凝固，盛出。
3. 下番茄，加一汤匙水，炒软出汁。
4. 倒回鸡蛋，放少量盐，翻匀后配几口米饭。

营养与搭配：鸡蛋提供蛋白质，番茄带来酸味和汁水。用它拌少量米饭，主食和蛋白质一起安排。

怎么少量吃：酸味让你更不舒服时，就换下面的豆腐汤，不必勉强吃。

制作依据：B25第3张。保持上半部两张成品近景，下半部食材与步骤小图的组织关系；原图的3次成品展示减为2次，腾出约2行营养说明。步骤缩为4格，保留原图清晰的食物与做法主线，不换其他笔记模板。

## 05 虾仁豆腐汤｜舀到豆腐和虾，才吃到食物

食材（一次制作的用量，不是每日摄入目标）：嫩豆腐100克、虾仁40克、水约250毫升、少量盐。

1. 豆腐切小块，虾仁清理干净。
2. 水开下豆腐，小火煮约3分钟。
3. 加入虾仁，煮至虾肉完全不透明、熟透。
4. 放少量盐，舀豆腐和虾仁一起吃，不只喝清汤。

营养与搭配：虾仁和豆腐都是蛋白质来源。去掉爆炒步骤，少油、少调料；能接受时再配几口饭或面。

怎么少量吃：闻到虾味就反胃，可去掉虾仁做豆腐蛋花汤；虾过敏者不用虾。

## 06 菠菜鸡蛋汤｜吃得下蛋花，再添一点菜

食材（一次制作的用量，不是每日摄入目标）：菠菜40克、鸡蛋1个、水约250毫升、少量盐。

1. 菠菜洗净，沸水焯一下，捞出切短。
2. 另起锅烧水，放入菠菜。
3. 鸡蛋打散，缓缓淋入，煮至蛋花完全凝固。
4. 放少量盐，连蛋带菜舀几口，再搭少量主食。

营养与搭配：鸡蛋提供蛋白质，菠菜增加蔬菜和膳食纤维。切短后方便用勺舀，少盛汤，蛋花和菜都要吃到。

怎么少量吃：这一份是蛋和菜的搭配，不能用一碗菜汤替代一餐。

制作依据：B25第5张。保持上半部两张成品近景，下半部食材与步骤小图的组织关系；原图的3次成品展示减为2次，腾出约2行营养说明。步骤缩为4格，保留原图清晰的食物与做法主线，不换其他笔记模板。

## 07 玉米冬瓜汤｜把汤里的玉米也吃进去

食材（一次制作的用量，不是每日摄入目标）：熟甜玉米粒60克、冬瓜80克、水约250毫升、少量盐。

1. 冬瓜去皮去籽，切小丁。
2. 水开后下冬瓜，煮到软透。
3. 加入熟玉米粒，再煮至热透，放少量盐。
4. 舀玉米和冬瓜一起吃；搭几口前面的蛋或豆腐。

营养与搭配：玉米提供碳水化合物，冬瓜作为蔬菜。吃进玉米粒，能获得的食物营养比只喝清汤更实在。

怎么少量吃：这6种是换着吃的选择，不要求一顿吃齐。奶或原味酸奶能接受时，也可另作小份加餐。
