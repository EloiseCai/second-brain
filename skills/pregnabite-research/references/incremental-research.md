# 增量扩库与关键词量化

> 本主题详细配置。通用方法引用 [research-core](../../research-core/SKILL.md)，此处保留已有批次规模、领域示例及账号指标；小红书取证要求仅用于小红书研究。


## 先读库，再生成

每轮读取飞书当前六维池、问题卡、别名/合并记录、已生成未验证项、用户驳回项和已发布组合。生成记录包含批次日期、覆盖类别、新增ID、复用ID及新增理由。已有条目重新出现只补证；新增须说明改变了哪个任务、触发条件或实质障碍。身份或情绪换词不构成新问题。保留旧ID，子场景用父ID.序号；不清空、不重排。

先列覆盖地图：饮食、工作、出行、就医准备、信息整理、家庭协作、消费、休息、待产。每轮优先补空白或只有泛化标签的类别。生活场景至少有“触发时刻＋具体任务”；痛点至少有“要作出的选择＋卡住原因＋希望的结果”。情绪必须关联触发事件，不能把所有人标成焦虑。

## 任务场景展开示例（40项，全部为AI探索种子）

以下是扩库时可比对的候选，尚未证明存在真实需求，不直接赋予PB-P问题证据状态。不得每轮重新生成这40项。

| 类别 | 五个可进一步组合的任务场景 |
| --- | --- |
| 出门与工作 | 出门前十分钟选早餐；工作中临时加班安排晚餐；轮班交接时安排休息和进食；会议连续时安排饮水与如厕；产检预约撞上工作安排请假 |
| 点餐与采购 | 午休在便利店凑一餐；外卖菜单看不到完整食材；家庭聚餐要表达自己的饮食选择；采购时按一个人份量避免剩菜；家里缺菜时替换菜单食材 |
| 就医准备 | 第一次预约时整理要问的问题；检查前核对院方准备要求；复诊前找齐不同日期报告；就诊后整理医生已经交代的事项；家属代办时交接证件和材料 |
| 信息整理 | 刷到两种相反说法时核对适用条件；收藏多篇清单后去重；临时出现疑问时整理给医生的描述；多个提醒来源冲突时整理日程；换医院时整理已有检查资料 |
| 家庭协作 | 家人买回不想吃的食物时沟通替换；做饭者按自己口味做菜时说明需求；伴侣出差前安排家务交接；照顾大宝时安排自己的就诊时间；亲友反复提建议时说明已确认安排 |
| 消费与预算 | 尺码变化后决定买多少衣物；比较待产清单时删除重复物品；面对套装优惠时核对实际所需；准备二手物品时列检查项；临时需购买用品时区分马上用与以后用 |
| 出行与休息 | 通勤换乘时找可休息位置；出门前确认厕所与休息点；短途外出时整理随身物品；夜间醒来后记录影响睡眠的条件；白天疲惫但有固定任务时重新排优先级 |
| 待产安排 | 按医院清单整理待产包；把证件材料分交家属保管；确定陪同人及备用联系人；整理到院路线和交通备选；入院前交接家中孩子及日常事务 |

从上述任务追问具体卡点，例如“预约和会议冲突，哪些事项先确认才能安排请假”，继续拆对象、选择、限制、已有办法和期望输出。仅有“工作焦虑”“产检麻烦”退回重写。健康和法律解答另行核验，本清单只用于寻找问题。

身份可在原池上探索远程工作、跨城通勤、弹性工作、就近无家属协助、伴侣异地、多人共同照料、还需照顾其他家人、临时异地居住等实际条件；条件重叠可多选。情绪补充着急（任务逼近）、挫败（尝试失败）、内疚（角色冲突）、孤单（缺少回应）、尴尬（不便表达）、失落（期待落空）、烦躁（反复打断）、犹豫（选择代价）；均先标假设。障碍细化到无法开火、无冷藏空间、步骤依赖他人、时间不可自定、资料跨平台、说明缺少适用条件、预算限制、路程长、物品携带不便、重复输入、无法持续记录等；解释它如何阻止任务，不停留在“条件不足”。孕周仅使用真实分期与明确孕周，不为数量捏造阶段。

## 关键词数据卡与筛选

飞书呈现只用《用户洞察》的一个“关键词搜索”分区、一张统一表。表内仅放实际检索到、可自然嵌入笔记的词或紧凑短词组；完整问题句即便平台返回过，也只作为问题线索，不能混入埋词表。判断词与句要看整体结构，不凭“什么”等单字机械剔除真实短词。大词、长尾词同表展示，长尾行标父词。按同一平台原始指数全表降序排序，每次新词加入或原词指数更新后都重排全表，将词放在正确位置；展示时万级保留一位小数写成“几点几万”，千级保留一位小数写成“K”，不足千约到百位。原值保留在取数记录，不能用已缩写的展示值重新排序。新批次原位更新词值和来源；不要按日期拆出多个拓词档案、旧词表、过程稿或重复说明。原始返回词和查询过程可保留在研究工作记录中，飞书正文只呈现当前可用词库与简洁口径。

词库的目的明确写在分区开头：第一，比较同一平台同一指标下的相关词，观察选题角度是否有搜索信号；第二，挑与笔记回答的问题一致的高指数词，放入标题、正文或图片文字。只有词与内容确实相符才埋入，不能为了指数硬套不相关词；搜索指数本身不替代问题与情绪证据。

### 系统扩词：从大词走到可埋入笔记的小词

每轮先建覆盖矩阵，横轴为备孕、孕早中晚期、产后及必要的具体时段，纵轴为饮食安排、具体食物、补剂、检查、身体变化、情绪、待产、家庭协作和同类工具。每个格子先找一个大词，再按「任务对象（早餐/外卖/糖耐/胎动）×限制条件（孕早期/控糖/上班/家常菜）×用户用词变体（同义词/简称）」生成**短词或短词组**。完整问句留在问题卡，不硬塞进关键词表。

先搜大词，完整抄录平台返回的相关词、联想词和当页指数；结果多于一页时继续翻页。然后选出现具体任务、阶段或限制的词作为第二轮种子，再搜一次，直到其子词不再产生新的具体问题。不要只靠 AI 脑补长尾，也不要只看第一个搜索结果。已采词按标准化词面、父词与含义去重：同义词可以保留各自真实指数，实质相同的问题共用问题 ID。

每轮记录覆盖矩阵中的已查、待查和无结果格，连同查询种子数、翻页数、返回词数、去重词数、筛入词数及筛选理由。优先补没有覆盖的格子和能改变问题定义的新词；同一格连续两轮只产出近义词时转去查另一个场景。停止扩词的依据是本批覆盖和新增信息趋于重复，不是凑满几个词或达到固定页数。会员期有限时先跑高相关大词和多页结果，再跑子任务词、跨阶段词与工具词；将尚未查的格子明确留给下批。

例如「孕期控糖」展开为「孕期控糖早餐／主食／水果／零食」，再核对「糖耐前一天注意事项／糖耐正常值范围」；前组可能对应日常配餐，后组可能对应检查准备或读结果，不能合成一个笼统的“控糖焦虑”。以短词指数决定埋词候选，以用户原话、评论和求助材料核对具体卡点与当下情绪。高指数说明该平台的相对检索信号，不能单独证明某个用户问题或某种情绪。

使用当轮实际可访问的平台查词；已登录的66190可以直接记录页面显示的“月搜索指数”。聚光暂无权限、千瓜认证审核中时继续查已可用来源，不等待。其他平台当前字段和会员权限以页面为准；平台宣传页不填入数值栏。

大词与长尾词同时入库，以父词ID关联：大词指向问题大类，短词组指向具体任务或处境。关键词必须是平台实际可检索的词或短词组；“备孕一日三餐怎么吃”这类完整问题句属于问题假设，除非平台确实显示其为搜索词，否则不放关键词栏。记录词层级、人群阶段、父词、关联问题及拟承接笔记；两类词分别比较，不把大词指数转嫁给长尾。初批检索种子包括备孕、备孕食谱、孕期食谱、孕期早餐、产后修复、产后饮食，再根据实际联想扩展。

搜索量/指数帮助选择笔记埋词，并提示需要追查的需求方向；主要结论仍是用户在什么处境遇到什么具体问题、困惑与情绪。标记实际有数值、平台显示0、低于披露门槛、未收录、无权限或未查询。零值与无数据分开，先查近义词和父词；具体卡点与情绪再用原帖、评论或真实反馈核对。

选题交接增加“父级大词→具体长尾词→搜索意图→笔记哪个位置直接回答→发布后实际搜索来源/搜索词数据”。标题、开头、正文及图片自然回答，不为堆词偏离原意。发布后搜索来源只能来自后台真实数据，不用总观看量推算。

每词一行：原词｜阶段/父词｜关联问题ID｜平台与报表｜指标原名/单位｜页面数值｜页面显示的统计月或窗口｜采集日期与批次月｜页面链接｜拟埋词位置。页面只标“月搜索指数”而没有显示对应月份时，记“页面未展示”，并保留取数批次月；照常记录与使用页面数值，不自行补造统计月。没有数据写未取得；指数不换算人数，笔记数、互动量、联想顺序不代替指数。不同平台的值分开保存。

数值按平台字段原名记录。66190显示“月搜索指数”就记作月搜索指数，并在同一平台同一批次内比较候选词；不额外要求算法公开才可用于本轮筛词。平台若显示统计月份就照录；未显示则以取数月作批次标识。其他平台的“热度值”“相关长尾词条数”和笔记供给另列，不能改名为月搜索指数。会员锁定、认证审核中的字段只记访问状态。

每批同平台、同指标的相关词可用数据分位作相对比较：关键词相对分位＝100×(低于该值的词数＋0.5×同值词数)/有效词数。保存完整候选集、取数批次、有效N及缺失数；只有1词时不计算，没有数据不排名。它用于选埋词与补查顺序，不代表笔记成功率；不把同义词指数相加。

先按备孕、孕期或产后修复问题相关性与真实困惑证据筛选，再参考关键词相对分位、可得的同口径趋势、具体未解决问号与可交付答案决定补查或小规模测试。高指数泛词定位问题大类；短长尾词可能更适合具体内容。保留长尾探索，不凭固定指数门槛淘汰问题。初批不编综合权重，积累发布表现后再检验筛词方法。
