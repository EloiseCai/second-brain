# 封面机制与数据反馈

## 分析对象

先实际读取原帖封面、发布标题、正文及整组图片，确认封面身份与完整语境；分析本账号时核对线上最终封面版本，草稿不能直接当发布事实。记录具体素材路径/URL、图片编号、版本或采集日期。无法查看实际图时标待补，不能从文字描述推断字体、层级、布局或视觉效果。

## 封面记录卡

每个样本保留以下证据，分析放在对应规律条目内部：

- 人群与场景、具体问题、情绪线索及证据；封面和发布标题各自原文。
- 第一眼看见什么：主体、构图、字号/对比、文字层级、信息密度、留白、视角与视觉异常点；描述实际可见组合，不仅贴“高级”“吸睛”标签。
- 点击机制：结果预览、身份代入、情绪共鸣、悬念/信息缺口、反差、问题诊断、比较选择、具体证据等，可组合但不凑类型。
- 点击动机：读者具体想知道什么；封面已经给出什么、还留下什么；答案在哪页/段兑现。价值可来自实用、有趣、好奇或被理解，不要求每张封面直接公开全部答案。
- 标题与画面关系：互补、重复或矛盾；分别看封面单独可识别性与标题组合后的预期。原尺寸与信息流缩略尺寸均实际查看；仅编辑自检不能声称用户测试。
- 可学的具体动作、适用场景、不可照搬点、来源与已知数据、待验证假设。

## 手法候选与边界

| 手法 | 观察点与可测试变量 | 必须兑现 |
| --- | --- | --- |
| 悬念/信息缺口 | 具体对象的局部、反常安排、留下一个有意义的问号 | 知道与什么问题有关，打开后有真实答案及明确落点 |
| 好奇/视觉反差 | 大小、摆放、材料或前后状态中不同寻常的地方 | 反差真实或明确为说明示意，不伪造效果对比 |
| 情绪共鸣/身份代入 | 真实处境中的两难、疲惫、期待、被理解等 | 情绪有依据，不默认所有孕妈焦虑，不羞辱或制造医学恐慌 |
| 认知反差/纠误 | 有证据的预期与事实差别，具体选择的意外解释 | 关键条件不隐藏，不将争议包装为确定真相 |
| 结果预览/具体证据 | 清单、完成结果、实物、真实产品输出 | 数量与效果由内文及真实功能支撑 |
| 比较/自我识别 | 两种选择、识别条件或场景差别 | 不凭图片诊断健康状态，不以虚构比例强化结论 |

这是研究与候选手法菜单，不能直接写成已验证规律。仍须至少2条独立素材重复出现相同做法组合才进候选，单条进观察；外部高赞不证明CTR高，更不证明该手法造成结果。封面对封面的结构对应继续遵守；视觉风格按本 Skill 的图片形式分类规则引用账号规范。用户已选定的具体成品版式保留，新手法应在方案阶段匹配。

## 本账号18%目标与反馈

PregnaBite用户于2026-09-24确认：18%是官方提供的封面CTR中位数，当前以18%作为优化目标。来源记录为“用户确认的官方参数”，不冒充本次已现场读取官方后台；无需因尚缺截图暂停采用目标，也不泛化为全平台所有账号的中位数。

每篇由review交接：实际封面与标题、机制与规律ID、平台CTR、曝光、统计窗口、与18%的百分点差距、内容消费及可用产品兴趣信号、来源分布（有则记）、改版/投放等影响因素。CTR沿平台口径，不用观看除曝光反推；高于18%也不自动证明转化成功。

规律条目中分开保留“实际观察 → 可能解释 → 不能判断 → 下次重点变量”。例如CTR从8.5%到18%的目标差距是9.5个百分点，不写9.5%。没有对应曝光与同窗口数据时写局限，不算显著性；累计CTR不能用来推算某次改封面的净效果。

后续实验可测试同一问题的不同机制，尽量保持内容承诺、受众、形式等接近，记录实际变化和版本。当前优先完善前期调研；保存实验候选不代表已获发布或改图授权。没有随机分流时称顺序探索，不能称严格A/B。点击上升但阅读/产品兴趣下降时，检查是否吸引了错误预期，不自动推崇高CTR版本。
