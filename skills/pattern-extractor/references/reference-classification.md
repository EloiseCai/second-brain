# 图片形式分类与统一风格

## 分类单位

分类以整组实际原图为依据，封面与内页分别记录。每条保存“整组主形式＋封面形式＋内页形式序列＋内容主题＋阅读任务”。混合组保留多种形式及顺序，不因封面是大字报便把整篇归成大字报。图片不可见的条目先补图，不根据标题代填。

## 形式标签词表（试行，随实际素材细化）

| 图片主体 | 具体形式 | 识别依据 |
| --- | --- | --- |
| 实物展示类 | 单品展示、食材平铺、一餐餐盘、一日餐次平铺、宫格合集、成品配做法、实物配说明、烹饪步骤连图 | 食物或物品本身承担识别、选择或操作示范；有配文仍归此类。实拍或绘制作为媒介标签 |
| 文字知识类 | 大字报、段落讲解、分块知识卡、问答卡、清单、比较表、日程/时间轴、总结卡 | 文字和表格承担主要信息；少量装饰人物不改变分类 |
| 示意图解类（遇到实际素材再细分） | 原理示意、流程关系图、结构标注图 | 图本身解释关系或机制；普通实物旁配说明仍归实物展示类 |

“图文对应”是组织方式，适用于上述不同类别，不另设为与实物展示并列的大类。同一组横跨类别时标记混合，并保留逐页形式；混合是整组属性。平铺、宫格、配说明、步骤等在所属类别内细分。分类先回答主要用什么承载信息，再记录怎样组织。

“食谱、补剂、控糖、孕吐”等另存为内容主题；“查询、比较、照做、记忆”等另存为阅读任务。同一主题允许多种形式，同一形式可以服务不同主题。

## 飞书记录与检索

标签维护在原素材“整组图片分析”的分类段；逐页说明引用原单图分析。已有主题目录及稳定链接保留，形式检索索引只保存分类和素材链接，不复制全文。全库盘点获得授权后再逐篇补标并在 B 类目录整理形式索引，未读条目不算已分类。

## 结构与账号风格

迁移对标的阅读路径、标题与正文关系、分组依据、表格逻辑、例子和总结功能。配色、字体、摄影处理、插画画风、背景和装饰统一引用账号视觉规范，不随每条对标切换。账号规范尚未制定时，将风格确定列为后续环节，不直接把对标外观设为账号规范。已获用户明确认可的具体成品设计仍保留，改动遵循本篇授权。

样例 B59：文字主导的混合知识图文；封面大字报；内页为比较表、日程说明卡、总结卡；主题孕期补剂安排；阅读任务为发现问题、查询组合、执行安排、记忆要点。
