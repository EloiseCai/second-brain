# 对标分析

本文件是单篇对标的图片、作者正文及两者关系分析的唯一规则源，适用于知识型图文各主题。`pattern-extractor` 负责完整分析并写回飞书原素材，同时负责后续跨素材归纳；`content-collector` 负责采集完整素材并调用本流程，`content-writer` 引用分析做本篇适配。单篇实际做法保留其适用情境。

用户于2026-10-04确认：逐模块拆解、逐句核对是通用分析逻辑，适用于不同平台、主题及文章形式。公众号长文、小红书正文和图片可读文本均执行；按实际载体确定模块及阅读顺序，不把某篇的表格单元套成通用模板。具体篇目的分组调整与标题选择只记录在该篇飞书稿，不升级为全局结构要求。

## 固定执行顺序（严格执行）

1. 完整读取：标题、封面、整组图片、作者正文和已有分析，确认来源可追溯。
2. 提取需求：写清服务对象、知识或行动缺口、希望得到的答案及原文位置；按下节核对整篇主旨。
3. 形式分类：按 [图片形式分类](reference-classification.md) 记录整组与逐页形式，内容主题另列。
4. 拆解内容：依下表分析标题牵引、信息关系、整组推进、正文补充、插图作用及总结价值。
5. 核验事实：合并相同主张，给出准确结论、可用表述与依据。
6. 借鉴 critique：检查我们是否读懂核心需求、结构与写法，说明怎样用于自己的内容；修改后复核。
7. 飞书回写：原位保存分析；调用 audience-report 去重并回写需求，取得问题ID及链接后补回素材。
8. 完成验收：回读分析与洞察，按文末验收逐项核对。只完成分析或只生成交接包时，不能称需求已回写。

这是一个连续执行环节。已有分析完整、来源未变时直接引用；只补缺项及受新证据影响的部分。需求仍不能准确概括整篇时先修正，不将偏题归纳传播到洞察库和选题。新入库调用本流程；全库历史重分析按用户明确授权范围执行。

## 核心需求提取（严格执行）

执行 [具体场景与对标角度保留](../../writing-core/references/angle-fidelity.md)。需求卡先保留原帖具体触发情境、眼前选择和承诺，再提炼通用规律；在原有“可用角度”中说明值得沿用的具体入口及其依据。回写用户洞察时沿用这些具体信息，不能只剩主题类别。跨篇共性不替代每篇的独特角度。

基于完整原帖，先从发布标题、封面承诺和整组主体内容共同判断“服务谁、对方不知道什么或不会做什么、希望得到什么答案”。每项归纳指向原文具体位置，核心需求必须能解释整组主要内容为何存在。再分析正文经历如何引出或补充该需求。作者经历中的结果落差、情绪、检查结果等仅在整篇确实围绕它解决问题时才进入核心需求，不默认读者也有同样经历，不强套“努力—失败”模板。

明确第一人称经历可记为“作者自述／已有直接表达”，提取其合理需求和叙述角度；内容讲解反映的需求记为“内容推断”。两者均可入库，来源性质集中记录一次；前者不因作者身份一概降级，后者不冒充实际求助。医学因果引用素材中的事实核验。流量用于选源，需求普遍性由独立证据支持。

需求卡记录“服务对象→知识或行动缺口→希望得到的答案→原文依据→可用角度”。自述作为补充；不强制每篇都有失败经历或情绪。需求 critique 至少核对：能否解释标题、封面和主体内容；是否把引子当主旨；是否擅自增加读者前提；是否落到具体问号。

## 阅读与证据（严格执行）

通读当前素材文档、发布标题及作者正文，实际查看整组原图。保存账号路径、笔记ID、原帖链接、图片顺序、封面身份、采集日期和分析日期。图片缺失或文字不可读时指出具体位置，补齐后再分析。来源和日期集中一处，分析正文直接写信息作用、关系、借鉴方法与事实结论。

定位以页码及实际区域名称为主，例如“P02表格的原因列”“正文开头经历段”；需要精确引用时再使用元素ID。大字报式连续一句话或一段话按整体分析，换行属于排版。数量与字数仅在解释容量或支持制作时使用，不以统计标题、段落、行数代替信息分析。

## 信息与写法分析（严格执行）

正文分析同时交付连续结构单元及组内逐句索引，定义与放行要求引用 `../../body-writer/SKILL.md` 的“对标逐句模仿”。每个重复模块分别记录起止位置、实际组成、句子作用、数量及与相邻模块的衔接；角色副标题、条件、例子、贴士、转场和收尾不能被大类摘要吞掉。“六种蔬菜”“营养解释”等总览只作导航，不能替代各段的独立拆解。原文某段有处理提醒而另一段没有，分别如实记录；规律总结不得把不同段落强行变成同一模板。缺少这层索引的旧分析须在引用前补齐，不标为已满足逐句写作输入。

整组分析须交付供写作引用的“逐页信息需求表”：页数、每页阅读任务、信息关系、独立食物/例子数量、每项解释需要回答什么、插图指认什么。数量用于保证内容容量，不能因“不机械数数”而省略；也不能用数量代替作用分析。特别保留首页与后续页的方向变化，例如“7项谨慎选择 → 5页各2项推荐”，不能只概括为“食物图配说明”，否则会丢失前后逻辑。记录原图真实结构，具体主题知识由下游据此查证选材；写作顺序及数量放行统一引用 `../../image-copy-writer/SKILL.md` 的“先确定原图信息需求，再查证写作”，不另存重复规则。

先按 [图片形式分类](reference-classification.md) 记录整组、封面与内页形式，内容主题另列。借鉴信息组织、关系与写作手法；原帖的配色、字体、纸张质感和装饰用于解释阅读作用，不自动成为本账号制作要求。制作统一引用账号已确认视觉规范；规范尚未制定时保留待确认项。

| 维度 | 要回答的问题 |
| --- | --- |
| 整篇阅读任务 | 读者正遇到什么，标题为何与其有关，读完得到什么；图片与正文如何共同完成任务 |
| 页面形式与作用 | 用自然语言说清实际布局，例如“大字报标题＋关键词笔触”“标题下方比较表＋表后总结”；说明它帮助读者注意、查询、理解、选择或记忆什么 |
| 标题与下属内容 | 整体标题怎样提出问题、给出判断与阅读预期，表格/分块怎样回答；代入、情绪、好奇按原句作用分析，不要求集齐 |
| 信息内部关系 | 表格逐列说明放什么、为何相邻，每行回答什么，行间如何并列/比较；分块说明理由、条件、例子、行动怎样连接。用具体内容说明关系 |
| 插图与视觉表达 | 图、人物、符号、色彩、关键词强调怎样配合信息；解释示范、指认、情绪、陪伴、记忆等作用，装饰也可有表达价值 |
| 整组推进与总结 | 每页接住什么问题，怎样带向下一步；查询表、执行例子、记忆总结各有什么分工。总结把细节压成原则、口诀或行动提示的作用应保留 |
| 作者正文与图片分工 | 正文怎样补场景、经历、情绪、解释、转场、行动与互动；逐段分析展开顺序、句式、语气、具体细节与结尾，说明实际互补关系，不逐页复述图片 |
| 自述与痛点 | 先按本文件的核心需求提取规则确定整篇核心需求，再说明作者自述怎样引出或补充它；提炼有依据的处境和写法，不把作者个体经历自动设为读者必有的困境 |
| 借鉴方法 | 写清值得保留的表达机制、适合的选题、要准备的信息，以及本主题如何安排到图片和正文 |

自述可作为具名来源的真实痛点线索。需求卡记录“服务对象→知识或行动缺口→希望得到的答案→原文依据→可用角度”，具体经历作为补充，医学因果另查证。创作可用原案例引用、读者场景或账号真实经历承载叙述结构。每篇完成后连续调用 audience-report 的“对标需求回写”模式，将需求按任务、触发场景与实质障碍去重并写入账号现有《用户洞察》，回读成功后在素材分析链接对应问题ID。完整叙述与知识依据留在素材，问题卡只保留必要摘录、需求和链接。作者自述与由内容反推的需求分别标注来源性质，来源性质按本文件记录；去重与写回规则引用 audience-report。单篇来源范围只集中记录一次。

## 内容核验与可用知识（严格执行）

涉及营养、健康、数据、因果、效果与操作建议时，当场检索原始研究、权威指南或适用产品说明，核对具体人群、剂型、剂量及条件。跨标题、图片与正文的相同主张合并核验一次，列明涉及位置；引用来源只保存一份。

输出“原主张及位置｜核验结论｜可用于写作的准确表述｜支持依据链接”。有证据支持的直接说明可用内容；与证据冲突的明确指出错误并给正确结论；有条件成立的把条件与可用答案写在一起。检索后仍证据不足时，明确哪项主张缺支持及已查来源，未发现依据不等于已证伪，不以笼统的“待核验/不能作为依据迁移”代替工作。

核验纠正具体知识，表达分析继续提炼有价值的标题、正文、图表与叙述方法。互动表现作为学习优先级与选源依据；事实结论依据研究与指南。

## 借鉴 critique（严格执行）

审查我们的分析与借鉴方案：是否解释原内容为何这样组织？是否保留标题牵引、信息关系、图文互补、总结帮助记忆的作用？自述是否提炼成有来源的痛点和写法？迁移后读者能否直观理解并作出选择？事实是否给出结论与准确表达？例子与解释是否齐全？

给出具体的“原做法→我们怎样用→需要补什么→落实结果”。不为完成critique凑对标缺点或擅自删页；没有具体选题时交付可复用借鉴方法。知识页各有实质信息，封面、引导、总结各有阅读任务；有效复现与无效复述按是否增加理解、记忆或行动价值区分。用直接结果、生活例子与明确关系减少计算和流程负担。

## 飞书唯一存储位置

沿用 `02_内容素材/对应笔记/笔记图片`，原始作者正文保留在 `笔记信息`：

- 现有三列表格的“单图分析”：按自然信息单元写形式、实际内容、内部关系、阅读作用与借鉴方法；同一行图片列保留原图。
- 表后“整组图片分析”：维护整组推进、正文写法与图文分工、自述痛点卡、知识核验结果与来源、借鉴critique。以页码引用细节，避免重复存储。
- 来源、日期放简短来源说明；进度和访问异常放检查报告。分析正文不写“本次已读/尚未启动/可用于讨论”等过程措辞。图片说明仅描述可见画面与文字，不复制分析或放核验占位句。

通读后原位整理有效信息。写后回读，核对全部原图、顺序、来源与作者原文完整；不另建第三个子文档、本地分析副本或平行知识库。

## 引用、更新与历史补齐

新入库即执行本标准。完整且原图未变的分析可直接引用；旧素材缺项则原位补齐。引用使用“飞书URL＋页码/区域或正文段＋分析日期”，创作文档只保存本篇转化。事实或素材变化时更新原记录，并复核受影响的创作。

先完成一组试分析，用户确认深度后按同一标准批量处理；已有全批授权则依授权执行。当前试分析阶段保留用户确认节点。用户已删除或排除的来源维持原状态。

## 分析验收（严格执行）

1. 全部图片与作者正文都有具体信息作用分析，整体语句未被机械按行切碎。
2. 表格行列、正文块、标题、插图及前后页怎样共同帮助理解已说明，数量统计仅作必要辅助。
3. 正文补充的场景、情绪、解释及叙述手法清楚，自述有痛点提炼与入库适用判断。
4. 实质事实完成检索，交付结论、准确表述及直接依据；证据不足精确到主张。
5. critique指导我们借鉴，正确识别总结与记忆价值，不以挑刺代替学习。
6. 飞书记录唯一，原始素材完整，引用可定位；实际访问缺口进入报告。
7. 图片形式与内容主题分列，混合组保留逐页形式；需求已回写《用户洞察》并可按问题ID双向定位。实际写入失败时报告具体缺口。
