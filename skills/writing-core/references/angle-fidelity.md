# 具体场景与对标角度保留

## 从原内容提取角度

先解释原帖为什么值得这个读者点开，再归纳写作结构。按已有需求卡记录：原文及位置 → 具体触发场景 → 眼前要解决的选择 → 原帖承诺的答案 → 值得借鉴的角度。保留会改变答案的时间、触发事件、操作条件和目标；原文没说的条件不补造。

例如“半夜饿醒，想找醒来就能吃、不会吃得太撑的东西”，要保留半夜醒来、当次进食的选择和便捷性；只写成“孕期饮食需求”“营养搭配”会丢掉信息。此例不代表所有夜间饥饿者都有这些条件，实际采用须对应来源。

每篇对标分别提取，不先把多篇压成共同的大主题。主对标、辅助对标都可能提供值得采用的具体角度；这些称呼不预先决定其内容价值。事实核验纠正具体主张，保留有依据的需求和表达角度，不因一项功效错误整篇只剩版式可借。

## 选题与模板各自的作用

在原有对标映射中区分三种用途，允许同一篇兼任：
- 内容角度来源：本篇帮助谁、在什么处境回答什么问题。
- 信息结构来源：答案怎样分组、排序、举例和跨页展开。
- 语言写法来源：怎样提问、解释、强调和承接。

内容角度须与本篇具体问题相符；结构和语言可跨主题借鉴，但必须适配当前问题。互动更高、图片更完整或产品更容易承接，都不能单独成为改掉具体角度的理由。图组仍整体分析、整体适配；适配不了就换合适图组，不为套模板扩大题意，也不退化为只抄外观。

将原始题意、当前用户确认方向和本轮选用角度并排核对，在现有 Pain / Angle / 对标映射中记录具体差异及确认依据。已有明确授权直接执行；尚未获授权的实质改题放回现有方向确认节点，不增加每个模块的人工确认。AI 文档中的“用户已确认”不能自动充当可核对的用户授权，更不能抵消用户当前纠正。

## 写作和 critique 的落实

标题、封面、图片主体和正文必须共同兑现选中的具体问题。具体场景不能只出现在开头或末页的一句话，而主体大部分都在回答更宽泛的题。无需每句重复场景关键词，检查的是答案的实际用途。

每次方向交接、Brief 完成、模块和整篇审查，使用同一份原文依据核对：
1. 原帖及用户选中的具体角度是什么？本稿保留了哪些关键条件，实际落在何处？
2. 本稿的主要答案是否仍帮助读者完成当时的选择？点出实际答案，不能只说“符合主题”。
3. 若删掉开头的场景词，主体仍是一份通用清单，检查具体处境是否改变了选择标准、例子、顺序或操作；仅贴场景标签而未作适配，退回修改。
4. 额外知识、全天安排、产品功能是否挤掉核心答案？没有直接帮助的内容移出本篇；必要背景保留并说明其作用。

审查结论同时对照原始题意与当前确认方向，不能只检查本稿是否符合 AI 自己写出的 Brief。发现偏移，回到最早变更处修正，并复查受影响的标题、图片、正文与产品段；不靠补一句原关键词宣告修复。

020 回查实例：原始条目包含“尤其晚上还会饿醒”，制作方案把它降为“晚间加餐只是其中一个餐次”，主体转为从早到晚六餐。若本篇选择夜间饥饿角度，这份六餐方案不能通过；应围绕夜间当次吃什么、如何方便准备等有来源的问题展开，具体食物与建议另核验。若用户另行明确选择全天安排，则记为另一个内容方向，不称为完整保留夜宵角度。此回查证明规则能指出该方案的偏移，不代表后续文章质量已验证。
