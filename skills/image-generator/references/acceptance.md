# 封面与配图统一验收

本表由 image-copy-writer、cover-generator、image-generator 共用。通用检查只存这里；品牌颜色、字体、蒙版、装饰及页脚参数读取主题包指向的当前飞书规范和已确认标准图，不另存副本。

## 三个执行位置

1. 图片文案阶段：对照已确认题意、原图及完整分析，核对切入角度、信息关系、数量和文字。公众号先读取当前完整正文，明确每图服务的具体段落；小红书遵循先图片规划后发布正文的顺序。
2. 生成前：将上述对应关系及品牌规范落实到完整提示词。缺项时修正已有 Brief 的对应部分，不能只在聊天中说明以后注意。沿用已有文本审批和候选选择节点，不新增逐项用户审批。
3. 生成后：查看实际图片，再逐项核对下表。提示词、文件存在及工具成功均不能替代实图验收。局部反馈只修改问题及受影响部分，保留已认可的风格与内容。

## 按实际图片检查

| 项目 | 实际检查与退回条件 |
| --- | --- |
| 风格统一 | 将封面、全部内页与账号标准图并排看。配色、字体、强调方式、图片处理、装饰和品牌区是否沿用获批规范？不能因为换了对标或平台就自行换风格；跨平台尺寸和布局依平台要求适配。 |
| 切入角度准确 | 先只看图片，用一句话复述它在回答谁的什么具体问题，再对照已确认 Angle、标题承诺及对应正文。比如“半夜饿醒怎么选宵夜”不能漂移为泛泛的“一日饮食”；只出现相同主题词不算角度一致。封面可保留悬念，但具体问题与阅读预期要成立。 |
| 信息作用与结构对应 | 核对原分析中每个区域的用途、数量、内部关系和阅读顺序，与本篇已批映射逐项对应。一碗四种食物展示的是搭配关系，不能用一碗单一食物代替。公众号配图逐一指向正文段落，实际补充、解释或概括该段；小红书按所选整组的逐页信息需求验收。平台切换不自动继承小红书页数。 |
| 画面视角与对象准确 | 区分内容角度与拍摄视角：按获批 Brief 检查俯拍、斜拍、主体位置和构图是否便于辨识信息；食物、餐具、数量、标签指向与文字相符。具体视角随已批方案，不要求所有主题固定同一拍摄角度。 |
| 文案与知识准确 | 逐字回对获批上图文字及已核验事实；遗漏、乱码、擅加功效、错误连线和标签错位都需修复。视觉正确不能抵消内容错误。 |
| 清楚、宽松、重点突出 | 完整尺寸检查全部文字及细节，手机阅读尺寸检查标题、重点和标签。间距执行 image-generator 主文件“通用图片留白与间距”；不能靠缩小字或删条目获得留白。 |
| 整组及交付完整 | 每张分别验收，再检查整组一致性与信息推进；选定页逐项对应实际文件、主项目归档和飞书展示位置。继续执行 content-writer 的 production-review，不以一张合格推定整组通过。 |

## 记录与用户查看

在当前飞书制作记录内维护“图片编号／要求来源／实际图像位置／具体差距／修正后复查”即可，不复制原始对标分析。没有实际看过的图写未验收；发现问题先修，再给用户看实际图片。用户评审采用同一组项目，沿用已有选择与确认节点。

规则回放：同样紫色但宵夜变成全天配餐，在切入角度项退回；内容正确但字体、蒙版自行更换，在风格项退回；食物数量相同但搭配关系消失，在信息结构项退回；文案无误但图片文字挤成一团，在可读性项退回。此为规则判定示例，不声称已生成或通过实图测试。
