# 封面与配图统一验收

本表由 image-copy-writer、cover-generator、image-generator 共用。通用检查只存这里；品牌颜色、字体、蒙版、装饰及页脚参数读取主题包指向的当前飞书规范和已确认标准图，不另存副本。

## 三个执行位置

1. 图片文案阶段：对照已确认题意、原图及完整分析，核对切入角度、信息关系、数量和文字。公众号先读取当前完整正文，明确每图服务的具体段落；小红书遵循先图片规划后发布正文的顺序。
2. 生成前：将上述对应关系及品牌规范落实到完整提示词。缺项时修正已有 Brief 的对应部分，不能只在聊天中说明以后注意。沿用已有文本审批和候选选择节点，不新增逐项用户审批。
3. 生成后：查看实际图片，再逐项核对下表。提示词、文件存在及工具成功均不能替代实图验收。局部反馈只修改问题及受影响部分，保留已认可的风格与内容。

## 对标页的文本量与主次核对（严格执行）

适用于按对标复刻的信息页，包括选模前A/B首张内容页。通用品牌封面按账号封面标准核对。选模后只使用用户已经选定的那套原图，不重新找模板。

文案送审前，在本篇Image Brief中按原图实际信息区建立简短对照：`区域及作用｜原图原句/位置与实际字数、可见行数｜本篇实际文字与字数｜原图视觉主次及所占空间｜差异与处理`。同一句大字报仍算一个语义单元；字数和行数用来发现容量漂移，不能替代信息关系分析。读不清原文时先补读，不猜计数。两侧字数使用相同口径（去空格换行，保留标点）；不自行设全篇统一百分比或强行逐字等长。

- 原图有几块独立信息，本篇逐块对应；新增理由、逐个对象解释、底部备注、条件、脚注等须单列为新增，未经明确批准直接退回。标题扩成建议段、一个短对比扩成多段解释，同样属于改变容量。
- 事实纠正先在原有信息位置用相近篇幅改写，保留原句作用、信息关系及重点。必须补充的解释优先由相关正文承接；无法在原容量内准确表达时，指出该处冲突并提出具体改法供用户确认，不能默默加字，也不能删除必要条件导致误导。
- “提高信息价值、讲清为什么、补齐知识”在原图的信息容量内执行，不授权新增文字区或提高知识点数量。参考图的短标签可以保持短标签，完整理由可在正文说明。
- 原图、大纲、文案、提示词和成图必须核对同一份映射。提示词逐区写入获批文字、主次层级、图文占比与留白要求，并明确不生成额外解释。原图作为结构参考、账号标准作为视觉参考，不能只交一份扩写后的文案让工具自由排版。
- 成图后将对标原图与输出按相同显示宽度并排看，再看手机缩略图：第一眼重点是否相同，标题是否仍大、辅助文字是否仍次要，图片区是否被压缩，原有留白是否被文字占据。逐区回读实际文字，不用提示词中的文字代替实图文字。
- critique须记录具体差异及修复结果，例如“原图短对比，本稿多出三段解释；删除多出的段落，复查主次恢复”。没有实际对照，或仍有未批准的增块、扩写、明显拥挤、主次变平，一律未通过；文案获批、配色统一和交接脚本通过均不能抵消这些问题。

截图纠错回放：若该页原图为“大标题＋两行说明＋一句短对比＋三杯比较”，加入逐杯理由和两段底部说明必须退回，即使三杯数量和排列一致。此结构仅是该页案例，不推广为所有图片模板。

## 按实际图片检查

| 项目 | 实际检查与退回条件 |
| --- | --- |
| 风格统一 | 将封面、全部内页与账号标准图并排看。配色、字体、强调方式、图片处理、装饰和品牌区是否沿用获批规范？不能因为换了对标或平台就自行换风格；跨平台尺寸和布局依平台要求适配。 |
| 切入角度准确 | 先只看图片，用一句话复述它在回答谁的什么具体问题，再对照已确认 Angle、标题承诺及对应正文。比如“半夜饿醒怎么选宵夜”不能漂移为泛泛的“一日饮食”；只出现相同主题词不算角度一致。封面可保留悬念，但具体问题与阅读预期要成立。 |
| 信息作用与结构对应 | 核对原分析中每个区域的用途、数量、内部关系和阅读顺序，与本篇已批映射逐项对应。一碗四种食物展示的是搭配关系，不能用一碗单一食物代替。公众号配图逐一指向正文段落，实际补充、解释或概括该段；小红书按所选整组的逐页信息需求验收。平台切换不自动继承小红书页数。 |
| 画面视角与对象准确 | 区分内容角度与拍摄视角：按获批 Brief 检查俯拍、斜拍、主体位置和构图是否便于辨识信息；食物、餐具、数量、标签指向与文字相符。具体视角随已批方案，不要求所有主题固定同一拍摄角度。 |
| 文案与知识准确 | 逐字回对获批上图文字及已核验事实；遗漏、乱码、擅加功效、错误连线和标签错位都需修复。视觉正确不能抵消内容错误。 |
| 清楚、宽松、重点突出 | 完整尺寸检查全部文字及细节，手机阅读尺寸检查标题、重点和标签。间距执行 image-generator 主文件“通用图片留白与间距”；不能靠缩小字或删条目获得留白。 |
| 整组及交付完整 | 每张分别验收，再检查整组一致性与信息推进；选定页逐项对应实际文件、主项目归档和飞书展示位置。继续执行 content-writer 的 production-review，不以一张合格推定整组通过。 |

## 逐张并排展示（用户已确认）

每张生成图在内部critique和用户交付时，均实际展示“左：对应对标原图／右：本篇生成图”，按相同显示宽度、保持各自比例并排，完整保留上下边缘；可另加手机缩略图，不用裁切、拉伸、重新生成原图或只给链接来凑对比。沿用上一步确定的原图→成稿页映射，不能拿风格图或另一篇近似图替代结构对标。通用品牌封面则与已确认的品牌标准图对照，并标明“品牌标准”，不冒充内页结构来源。

选模前A、B样张各自与其来源并排，用户仍在原选模节点选择；选模后逐页与已选整组对应原图并排。对比在本轮原有交付节点集中展示，不额外要求用户每张重新批准。每对标清来源笔记/原页、输出页与版本，下面简记文本量、信息作用、主次、图文比例和留白的实际差异及处理结果。

对比材料保存到本篇制作备注的验收区，与可发布图集分开，不作为额外发布页。飞书支持双栏时使用左右图；不支持时用可并排查看的对比预览并保留两张原图引用。生成后必须实际查看对比结果再写结论；记录对比位置和所比较文件版本，不能先写“通过”再补图。退回后只更新受影响页及其对比。

## 记录与用户查看

在当前飞书制作记录内维护“图片编号／要求来源／实际图像位置／具体差距／修正后复查”即可，不复制原始对标分析。没有实际看过的图写未验收；发现问题先修，再给用户看实际图片。用户评审采用同一组项目，沿用已有选择与确认节点。

规则回放：同样紫色但宵夜变成全天配餐，在切入角度项退回；内容正确但字体、蒙版自行更换，在风格项退回；食物数量相同但搭配关系消失，在信息结构项退回；文案无误但图片文字挤成一团，在可读性项退回。此为规则判定示例，不声称已生成或通过实图测试。
