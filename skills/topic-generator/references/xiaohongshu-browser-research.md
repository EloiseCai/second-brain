# 小红书登录态浏览器调研

当选题研究需要读取小红书高互动笔记的完整内容、呈现方式和评论补充，且普通网页检索只能返回摘要或受访问限制时，使用本流程。目标是像普通用户一样在已登录页面中只读检索、完整阅读笔记并记录可追溯证据，不使用平台摘要代替原文。

## 一、建立可用的登录态

1. 优先使用 `browser-act` 控制独立的有界面本地浏览器会话，并保留同一浏览器 profile，避免每次创建全新的空白环境。
2. 如果页面要求登录，打开 remote assist，把控制权交给用户完成扫码、验证码或账号登录。不得向用户索取密码、验证码或导出 Cookie。
3. 用户确认登录后收回控制权，检查页面是否出现个人入口、消息/通知等可见登录标志，再开始调研。登录标志只能证明当前会话可访问，不能用于采集无关账号信息。
4. 同一轮调研尽量复用当前 session。会话中断时重新打开同一 browser profile；不要因为一次页面失败就反复新建浏览器。

## 二、搜索与选样

1. 先按本轮人群与问题范围选择搜索种子，读取实际下拉词及相关搜索，再根据帖子正文和评论中的自然用词扩展长尾词。PregnaBite原有饮食搜索词仅是可选分支，不限制全人群研究。
2. 搜索结果页只用于发现候选。必须点击进入帖子详情，才能开始计入样本。
3. 每次页面跳转、打开详情、关闭弹层或滚动导致页面状态变化后，重新读取页面 state；不要复用已失效的元素索引。
4. 第一轮样本优先覆盖本轮互动较高、主题明确的笔记和近期求助帖。第二轮样本优先覆盖：
   - 与已确认主题直接相关、内容完整且互动较高的对标笔记；
   - 展开方式、信息结构或图文呈现值得拆解的笔记；
   - 可用来补充具体选择困难、追问或分歧的评论区。
5. 去除重复转载、同作者近似复制、营销模板和与选题只有关键词重合的内容。

## 三、什么算“完整查看 1 篇”

一篇帖子满足以下内容条件，才计入第二轮单题最低样本数：

- 已进入详情页并读到完整可见标题、作者、发布日期或可见时间；
- 已读完整可见正文；图文需查看整组图片或已有逐图文字，不能只看封面；
- 图文需记录各页的信息功能和排列顺序；视频需完整观看或获得可靠完整转写；
- 已记录帖子 URL、内容类型、检索词、读取日期、可见互动和评论访问范围；
- 评论可访问时，读取与选题直接相关的可见一级评论、作者回复和追问；评论不可访问时记录缺口，不因此取消完整笔记样本资格。

以下不计入完整样本：

- 搜索结果卡片、标题列表或搜索引擎摘要；
- 平台生成的 AI 总结、联想词、“大家都在搜”；
- 只看到封面、简介或评论数量；
- 无文字稿且没有完整观看或转写的视频。此类视频可作为补充线索，但不能冒充完整样本。

## 四、评论取证

1. 滚动到评论区，优先读取与选题有关并带可见点赞或回复链的具体提问、执行障碍、已有尝试、对答案的追问及不同意见；有相关回复链时展开查看。
2. 可引用短句作为需求证据，但不要保存与研究无关的用户名、头像或其他个人信息。
3. 将记录拆成：评论原话 → 所属帖子 → 可见互动 → 已知情境 → 卡住的选择 → 已有回复/继续追问 → 可以补入正文的副观点或提醒。
4. “收藏了”“求链接”“打卡”等互动不能直接归纳为具体需求；点赞、收藏、评论数也不能直接等同需求强度。
5. 只声明实际可见和实际读到的范围。评论未完全加载、排序不可控或回复无法展开时，明确写出访问缺口。

## 五、最低样本与停止条件

- 第二轮单题至少完整查看 3 篇独立相关笔记，并完成内容与呈现方式拆解；评论作为补充证据，记录实际可见范围。补充视频或其他平台资料只有在完整观看或获得可靠完整转写时才可按同一标准计入。
- 3 篇只是当前试行下限，不代表需求普遍性。样本观点冲突、作者过于同质或场景仍不清楚时继续扩样。
- 少于 3 篇时继续更换搜索词和候选；确实无法补足，记录“研究未完成：样本不足”，不能把结果写成已验证需求。
- 达到下限且已经能明确“主对标怎样展开、本篇核心承诺是什么、信息怎样推进、评论补充哪些副观点”后，可以停止扩样，避免为数量无限浏览。

## 六、研究记录格式

每篇至少记录：

- 检索词；
- 标题、作者、URL、内容类型、发布日期/可见时间；
- 可见互动数据及采集日期；
- 正文中与选题相关的事实或表述；
- 内容承诺、开头方式、信息顺序、段落或图片功能、具体例子、表达手法和正文/图片分工；
- 相关评论/回复短摘录及可确认阅读范围；
- 直接需求、创作者概括与 AI 推断的区分；
- 是否计入完整样本及原因。

本轮汇总记录：完整样本数、补充样本数、去重情况、主对标及选择理由、辅助对标手法、未采用帖及原因、评论副观点、明显分歧、访问缺口和推导出的文本方向。互动数据只能帮助判断内容受欢迎程度，不能单独证明某种呈现手法造成点赞；健康、营养和补剂答案仍须另用可靠资料核验。

## 七、行为边界

- 调研仅限只读：不点赞、不收藏、不关注、不发布、不评论、不私信。
- 不绕过验证码、登录或访问控制，不导出用户凭据和 Cookie。
- 浏览器或插件不可用时，可使用公开网页和其他社区补充，但必须标记平台差异与“小红书评论未验证”，不得伪装成本流程已完成。
