# 选定题研究要求

第二轮由topic-generator执行，输出交content-planner写入内容包。下文第一轮指可选的候选生成，指定题无第一轮时如实记录用户指定题意及来源。小红书样本门槛不移植公众号。

2. **第二轮：对标内容与文本方向调研。** 用户确认或调整候选后，围绕每个确定主题重新检索并完整阅读相关高互动笔记。重点拆解笔记讲了什么、怎样安排信息、如何让内容容易理解和接受，以及哪些呈现手法可能促成点赞、收藏或评论。评论用于补充正文可以回应的副观点、遗漏问题、反对意见和执行障碍。此轮回答“本篇具体讲什么、按什么顺序展开、怎样呈现”。只交付文本方向，不提前写标题、图片提示词或完整正文。

用户直接给出新选题也必须执行本轮平台定向检索，不因题意已经确定、已有洞察或旧对标库而跳过。小红书任务实际进入小红书检索、阅读详情和可访问评论；若尚未执行或访问受限，如实记录，不用其他平台搜索或库内回读冒充本轮检索。交接中区分同题内容依据与载体表达对标：前者回答用户具体困惑、现有解法及遗漏，后者回答故事推进、图文分工与语言容量。普通图文可以提供同题证据，不能自动充当漫画表达对标；旧漫画也不能代替新选题定向研究。用户追问是否调研时，报告实际检索日期、关键词、原帖链接、新增/复用身份和具体借鉴，不仅列作者或Skill名称。

第二轮至少新增一篇对标的要求继续保留。调用content-collector做定向完整采集，再由pattern-extractor完成所选对标分析；已有完整分析可回读复用并核对本篇适配，不启动无关的全库规律重提。总计至少3篇独立相关样本的旧要求仍保留。采集完成与分析完成分开登记；Topic Generator自身阅读原文，完成题意验证及相近参考的用途判断。

## 按当前内容形式选择三篇对标（2026-10-19确认）

先锁定本篇平台、载体与内容类型，再检索匹配的对标。小红书单题至少3篇有效对标，其中本轮至少1篇新增；漫画故事的3篇必须都是漫画叙事，知识型图文、时间表或清单只能作辅助事实/需求素材，不计入漫画故事对标数量。其他形式同样按各自阅读任务匹配，不能因主题相同就混用。优先同题同形式；确实缺少完全同题的漫画时继续检索相近人群和困境的漫画，逐篇说明关联及可借鉴机制，无法凑足适配样本如实保留缺口，不拿知识卡片补数。

固定执行：topic-generator定向检索与筛选 → content-collector查重、完整采集 → pattern-extractor逐篇分析 → topic-generator交接本篇研究 → 故事/策划。漫画分析须实际读取整组原图，说明人物目标、阻碍、动作反馈、转折、结尾、产品承接（如有）、短框容量及图文分工；交接列出3篇原帖与素材路径、分析位置、新增/复用身份、各自如何影响本篇写法。只有数量达标、完整采集及分析适配都完成才放行；不能以已读Skill、摘要或普通图文代替。

第二轮完成前增加“对标入库门”：先按笔记 ID 和规范化 URL 在当前账号素材库查重；已存在时回读并确认正文、图片/视频解析完整，缺失则补齐；不存在时调用 `content-collector` 完整入库。入库完成后，第二轮记录必须同时写出外部原帖 URL 与账号内素材路径。任一被引用对标仍只有评论、标题、摘要或不完整图片时，本轮状态只能写“待补材料”，不得标为“第二轮完成”或交给 `content-writer`。

第一轮发现的帖子可进入第二轮样本，但第二轮必须继续做主题内定向检索，并产出对标内容拆解，不能只把第一轮结果重新排版。定向研究通过后交content-planner；改变已确认题意时先确认。

- 第二轮的单题研究至少完整查看 3 篇独立、与该题直接相关的笔记。第一轮可用较宽的热点样本筛选候选；候选一经确认，第二轮必须达到单题下限并完成对标内容映射后才能交接。搜索结果卡片、仅标题/摘要、未读全文的帖子不计入；转载、重复发布和营销复制去重后计数。库内已读素材与本轮新检索可合计，**总计至少3篇，其中本轮至少新增1篇相关对标**。新增指本轮实际检索、完整阅读且查重后新纳入当前账号对标库的独立笔记，不把重读旧帖、补抓旧帖或重复发布计为新增；不要求一定是近期发布的帖子。由content-collector完成正式采集入库、pattern-extractor完成对标分析，记录旧库/新增身份、来源及日期。总数达标而新增不足时仍须补查。少于 3 篇时继续补查，确实无法补足则标为“研究未完成：样本不足”。评论访问情况单独记录，评论缺失不取消已完整阅读的笔记样本资格。

- 单条具体求助可保留为需求线索，但仍需查看另外的相关帖子作对照；不要求 3 篇都支持同一结论，也不为达标挑选或捏造一致证据。3 篇是研究下限，不是需求普遍性或内容正确性的证明，明显有分歧或场景覆盖不足时继续扩样。

- 第一轮候选可以暂时只保留外部检索记录；一旦某帖子被选入正式候选依据、第二轮样本、主/辅助对标或评论证据，必须在第二轮交付前完成素材库查重与完整入库。交接清单逐篇核对“原帖内容可读、全组图片/视频解析可读、评论证据可回到所属帖、素材路径可点击”四项，缺一项不得宣告完成。

- 流程参数记录（用户确认：2026-09-09）：单题最少完整查看 3 篇独立相关帖子；这是当前试行下限，后续可依据质量复盘调整。若选题或文案质量不好，回查该题样本记录，分别检查数量不足、来源同质、主对标选择、内容展开拆解、评论补充覆盖及写作执行问题；不自动把质量差归因于样本量，也不未经检验认定“3 篇足够”。需要扩样时保留补查前后的数量、来源和判断变化，形成调整依据。

- 素材库持续扩充后，优先补查与该题有关的新材料，比较是否新增场景、追问或相反证据；库规模增加不自动代表单题研究更充分。给后续复盘交接上述参数和实际样本记录，便于追溯。

- 给 content-writer 交接一份“两轮调研证据包”：第一轮保留问题ID、角度ID、方案ID/版本、六维组合与情绪依据、各渠道状态、解法缺口、功能状态、热点笔记、可见互动、候选理由和去重结果；第二轮补入定向检索词、至少 3 篇完整样本（其中本轮新增对标至少1篇，附采集位置、已有分析链接或尚未分析状态）、主对标的内容展开与呈现方式、辅助对标可借鉴手法、本篇核心承诺、建议的信息顺序、具体例子、评论副观点、对标原文/图片和事实核验缺口。对关注任务再交接“本篇解决的眼前问题 → 本文展示的具体结果 → 读者下次仍可向账号获得的帮助”三项内容方向，供 writer 放进正文推进；不提前拟定成品标题、自拟图片页数或写出完整正文。须如实交接原帖页数与逐页容量，连同已存飞书图片分析的链接、章节、修订号或更新时间；该数量是后续复刻输入。初步菜品只作候选，不限制后续按分析查证选材。

- 交接后由 content-writer 基于第二轮证据做场景表达与初稿。交接中保留原始具体题意、当前确认方向、所选对标角度及具体来源；正文主线落实能回答该问题的对标展开方式，评论副观点放入合适段落自然回应。若写作阶段发现证据与方向冲突，退回 topic-generator 定向补查，不重跑整轮。

若新采参考随后被选作正式逐页复刻模板，仍须在写图文前具备可读的逐页结构分析；该生产前置检查不能用“已采集”冒充。第二轮采用的对标必须完成适用形式的分析；未分析不能作为已完成交接。
