# 标题写作

本 Skill 是发布标题与图片标题的共用入口。`content-writer` 在图片文本规划、发布标题生成、成图验收和标题改稿时调用；不自行启动选题研究、图片生成或发布。单独调用时按用户授权的标题范围工作。

## 输入与规则引用（严格执行）

生成前确认：平台、账号/主题、标题角色、用户已确认题意与标题、本篇核心承诺、已经具备的实际内容及事实来源。图片标题另需方案 A/B、页码、标题层级、所属文本块/插图及其关系、对应原图标题与容量；依照 [整组图片内容分析](../content-collector/references/image-content-analysis.md) 引用来源位置。

按实际适用范围读取三层要求，写作和 critique 使用同一份引用清单：

| 层次 | 维护位置与使用方式 |
| --- | --- |
| 通用标题方法 | 本文件及本文件链接的发布标题参考；调用方只保留链接，不复制规则正文 |
| 平台要求 | 当前任务明确关联的平台规则文件或飞书章节；可以包含有证据的写作偏好。未建立专项要求时注明沿用通用方法，不编造“平台喜欢”或强制凑一层 |
| 主题要求 | 当前账号已确认的写作原则、禁用项、事实和产品资料的具体文件/飞书链接及章节；现场读取，不能凭主题关键词猜测。未拆出的规则引用现有真实位置，不假装新主题 Skill 已存在 |

引用记录包含来源、具体条目、读取/版本信息及适用标题角色。同一已读且未变化的来源本轮可以复用。必要规则不可访问时如实标为待核验，不能只挂链接就宣称已落实。当前用户明确要求优先；其余规则存在实质冲突时指出冲突，不能用更具体的标题措辞掩盖内容或事实缺口。

## 人群标签化（优先采用）

尽量使用让读者快速辨认“是否适合我”的人群标签，如身份/阶段、生活方式、偏好或有依据的情绪状态；“i人”“懒人”“焦虑”是可选表达，不是固定标签清单。标签与本篇实际服务对象、内容用途匹配，优先自然融入发布标题与封面标题，不要求每张内页重复，不为标签另加设计元素。

标签定位引用用户洞察的实际调研或用户明确指定。尤其焦虑、性格、困扰不能凭空安在读者身上；省事方法不能自动证明人群懒惰，i人也不自动等于社交焦虑。能用具体阶段或需求标签清楚识别时优先使用。尽量标签化不等于强制每条添加，生硬或无依据时调整。

每条标题 critique 增查：实际标签在哪里、对应哪个已确认人群/证据、该人群读完能得到什么；标签抢占题意、制造未证实困扰或与内容不符时退回。发布及图片标题均执行，不能仅数有没有标签。

通用模块放行与评论用法引用 `../writing-core/SKILL.md`；小红书与妈妈善食分别组合 `../xiaohongshu-writing/SKILL.md`、`../pregnabite-writing/SKILL.md`。其他平台/主题替换对应来源。

## 按标题角色执行

| 角色 | 内容范围与主要任务 | 对标依据 |
| --- | --- | --- |
| 发布标题 | 建立整篇的代入、情绪/好奇与点击后内容预期 | 当前账号标题规律库的实际原句及本篇适用的具体对标 |
| 封面标题 | 像发布标题一样建立整篇阅读预期，在真实画面和容量内灵活运用代入、情绪与好奇，给读者继续阅读的理由 | 当前方案所属原帖的真实封面标题及整组内容 |
| 内页标题 | 承接整组主线，点明本页具体问题、结论、选择或行动，并牵引读者读下去 | 该组对应内页的标题、正文及前后页关系 |
| 图片小标题 | 让读者识别所属信息块及与其他块的分类、因果、步骤或比较关系 | 对应原图小标题及其统领的文本块/插图 |

发布标题执行 [发布标题写作与独立 critique](references/publication-titles.md)。图片中的标题也执行下方共用步骤和对应角色的 critique，不退化为临时补一个主题名。内页/小标题的阅读牵引按本页功能判断，不机械要求每一个都制造悬念；适用的强表达、情绪与节奏仍应保留。

候选数量、发布字数等从调用方已确认要求传入；现有 `content-writer` 的“三个发布标题候选”不扩成每个图片标题三个候选，也不因有 A/B 两套自动扩成六个发布标题。图片标题数量、层级、行数和位置继续遵守对应原图及已锁定设计，不能借增强标题新增原图没有的标签、副标题或装饰。具体 Emoji、字数和主题禁用项按对应规则的实际适用范围核对；存在与已锁定设计的冲突时说明并解决，不能静默删掉任一要求。

## 效果与手法的区别

发布标题与图片标题都须检查内容预期、理解清晰度和承诺兑现。代入感、情绪、好奇是优先考虑的表达手法，能自然增强效果时使用，不要求每个标题集齐，不因缺少其中一项自动退回。逐项审查表示评估这些维度是否适用，不表示强加对应词语或句式；明确结论、具体收益、实用答案也可以提供阅读理由。按对应原句与标题角色判断，不为凑手法添加悬念、焦虑或画面元素。内页和小标题的预期落在本页或所属信息块，结合实际画面判断。

## 共用写作步骤（严格执行）

1. **从内容与原句出发。** 先读标题真正统领的内容、对应对标原句及前后语境，明确它提出什么问题、给出什么结论、为何值得继续读。先完成“原句及位置 → 表达作用与关系 → 本篇真实答案/事实来源”的映射，再写标题。不能先拼句再补来源。
2. **保留有效表达。** 迁移原句适用的语气、句式、信息顺序、节奏和情绪力度，用本篇事实改写；不照搬独特措辞、虚构经历或功效，不为体现原创改成抽象、拗口或弱化的表达。
3. **核对统领关系。** 标题的对象、范围、数字、条件与实际文本块逐项对应。封面的整篇承诺必须有内页/正文落点，内页标题须由本页实际内容回答，小标题不得把三个并列选择说成三步流程。写出与相邻标题的承接关系，不能只检查每句单独通顺。
4. **逐条 critique、改写并完整复审。** 执行下表，记录可定位的实际措辞、问题、落实的修改和复查证据。已确认标题按用户要求锁定；新内容不能兑现时回到内容处理或明确提出冲突，不擅改标题。
5. **接回实际图片。** 文案通过后才能进入提示词；成图后再核对实际标题文字、换行、层级及其与内容和插图的关系。提示词正确不代表成图通过。标题变化后重审其统领范围、相邻标题、相关提示词和已生成图片。

## 对标模仿的实际证据（严格执行）

发布标题、封面标题、内页标题和小标题均须在写前读取对应原句及其统领内容。逐条保存“完整原句与位置 → 人群识别/句式骨架/语气力度/信息先后/好奇与内容预期 → 本篇实际标题 → 下属答案位置”。长标题按语义整体分析，不把视觉换行拆成互不相关的标题。

写后将原句与本稿并排逐项核对，指出本篇实际保留了哪些写法、哪些因事实或标题角色调整及其理由。只换主题词、只贴来源链接、只有抽象规律名、用感叹号代替语气，均不放行。每个候选及 A/B 每个实际图片标题分别审；不能用发布标题通过替代图片标题，也不能借模仿擅改已确认标题。改后重审完整标题、内容兑现及相邻标题关系。

## 图片标题独立 critique（严格执行）

每个实际存在的图片标题都要检查，A/B 分别执行。记录 `方案/页码/标题ID → 角色 → 原句来源 → 本稿实际标题 → 下属内容位置 → 问题与修改 → 复查结论`；只记录引用和本篇结果，不复制原分析。

| 检查 | 可放行证据与退回条件 |
| --- | --- |
| 代入与明确性 | 在实际阅读语境中看得出对象与要解决的问题；只有主题词或空泛栏目名、需要备注解释用途时退回 |
| 情绪/好奇与阅读价值 | 指出实际词句提供的阅读理由与内容预期，以及内容如何回应；按上方“效果与手法的区别”评估代入、情绪和好奇，未采用的手法可注明不适用，不能为通过检查补造情绪。封面检查整篇预期，内页/小标题检查本页及信息块的阅读与识别作用，不能靠感叹号或标签判通过 |
| 承诺兑现 | 定位标题所承诺的具体答案、解释或行动；数量、范围或因果关系与下属内容不符即退回，不能把正文尚未写出的答案算作已经交付 |
| 忠实借鉴与力度 | 与对应原句比较实际语气、句式、节奏和信息功能；无故变弱、变拗口、只换主题词或借入不适用承诺时退回 |
| 整组关系与可读性 | 标题之间的并列/因果/步骤/总分关系与实际正文和插图一致；换序是否破坏依赖、标题是否争抢同一个答案都须说明。按真实画面检查行数、容量和扫读，不用漂亮版式抵消关系错误 |
| 三层规则 | 同时核对通用、当前平台、当前主题以及用户专项约束，指向本次读过的真实来源；未知不写通过 |

结论只用“通过／退回修改／待核验”。任一阻断项未解决就不交给下游生成；修改后重走适用检查，不能默认第二版通过，也不能把编辑判断写成真实用户点击或传播效果验证。

## 输出与规则更新

结果写回当前飞书创作文档的实际标题位置，来源映射与简短复查放同文档制作备注，不创建本地正文或方案副本。将已检查的当前文案、来源指针及仍存在的缺口交还调用方，保留用户原有标题/封面选择节点，不要求用户逐个审批内页标题。

收到长期规则修改意见时，先向用户确认适用范围是通用、平台还是主题，并列出实际将修改的 Skill 名称和来源条目；仅本篇改字不自动升级为长期规则。此前已经明确确认的范围直接沿用。当前通用标题规则归 `title-writer`；尚未单独拆出的平台/主题规则如实定位到现有文件或飞书章节。
