# 妈妈善食主题写作包

只在用户确认账号/主题为妈妈善食 PregnaBite 后使用。孕妇、孕周、饮食等语义可用于提出路由建议，不能代替用户首次路由确认。其他主题更换主题包，共用写作和平台包不变。

## 实际来源（现场读取，按本篇适用）

- 钩子原话与规律（`hook_library`）：[钩子原话与规律｜妈妈善食](https://my.feishu.cn/docx/JdDZdOdDpoA5TqxnO7vcsfPvnvf)，位于03_内容规律。hook-generator写前读取实际原句及机制，pattern-extractor在对标分析时增量维护；标题、图片与正文通过内容包引用已选钩子，不能只读抽象规律。通用方法见 hook-generator/references/hook-library.md。

- 定位：[定位总览](https://my.feishu.cn/docx/ZLxEdoKwnoe8t5xFpzQcVtOQnuc)。旧定位与用户最新确认冲突时以最新确认范围为准。
- 写作偏好：[写作模式持续记录](https://my.feishu.cn/docx/JHFhdwGe1oysVVx3n4Dcg4t8npc)。写前读取，交付前复核；其中“引用呈现”规定读者文章不显示引用编号，来源核验仍保存在制作备注，交付时检查正文与图片文字。本账号偏好不扩展为其他账号或平台官方规则。
- 统一封面：[妈妈善食封面标准](https://my.feishu.cn/docx/CUoud9EHdoRGB4xPZGEc44RknRc)中的“当前封面制作标准”及实际标准样图。用户于2026-10-02确认后续封面沿用此标准；页面后方候选仅留档。每次封面规划、生成及实图 critique 必读，标题、副标题、标签、主题图片和品牌页脚按该处区分固定形式与本篇变量；不在其他 Skill 重复保存视觉参数。
- 图片视觉：读取上述飞书写作原则中的品牌配色要求。妈妈善食使用紫色品牌配色；对标提供排版、信息结构与容量，不提供默认配色或写实/插画风格。封面、内页及实图 critique 均须核对品牌紫色是否落实，不能因选择了对标而沿用其颜色。具体色值及其他视觉细节引用已确认资产或本篇获批方案，不将临时选色宣称为品牌标准色值。
- 人群、问题证据与关键词：[用户洞察](https://my.feishu.cn/docx/F4y3dfCXsoapEpx0G5ecCLWjn4f)。原话、假设与搜索信号分开，按 `writing-core` 的场景证据规则使用。
- 置顶评论对标（`pinned_comment_benchmarks`）：[评论区引流对标库](https://my.feishu.cn/wiki/CPBywMM4Xi2TikkrQiTcDyICnfV)，位于本账号 `02_内容素材`。小红书 Hashtag 后由 pinned-comment-writer 读取原话、评论自身互动及逐句分析；产品能力仍引用下方产品资料，不移植对标账号的功能。具体承接形式按本篇选择，未固定成某一种话术。
- 平台限制：[运营手册与违禁清单](https://ccn0e915enia.feishu.cn/wiki/EKyMwztQaia6yDkL55lcw9oJndb)。只引用适用章节，不复制整套词库。
- 产品：引用当前账号产品资料及本篇用户确认；具体能力与拟发布句按 `content-writer/references/brief-approval.md` 交用户复核。不从资料遗漏推定功能不存在。
