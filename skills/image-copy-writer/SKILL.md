# 图片文本写作

每次续做先执行 `../content-writer/references/resume-contract.md`，回读飞书执行状态及实际材料；封面形式与A/B方案身份分开，沿用已完成研究，按当前节点补齐具体依赖。

输入：已确认题意、研究成果、两组对标及 `pattern-extractor` 的完整分析、关键词、事实、账号风格与产品复核状态。缺少材料交回具体环节补齐，不自行改选题。

图片规划和文案阶段先执行 `../image-generator/references/acceptance.md` 的前置检查，生成阶段继续引用同一表。公众号须先读 `../wechat-writer/SKILL.md` 及本篇当前完整正文，再建立段落到图片的对应；下方逐块结构学习用于配图阶段，不作为写公众号正文的前置条件，也不自动继承小红书整组页数。

每页图片文本必须执行 [至少三轮复核](../content-writer/references/three-pass-review.md)：写前先看对标容量与整体组织，拟文后在出图前细看结构；每轮都完整核对本模块的原意对应、事实推理、表达容量及全部适用要求，连续执行至少三轮。单页超量先精简，拆页须按协议确认。

## 三部分组合

漫画优先执行 [首页即封面的情景建立规则](../story-builder/references/comic-storyboard.md)，不进入下述通用品牌封面替代首页／P02样张模式。首页实际文字明确人物身份与处境，精简不能删掉理解必需的时刻、阻碍和动作；与人物分镜共同验收。

必读通用包 `../writing-core/SKILL.md`；平台为小红书时读 `../xiaohongshu-writing/SKILL.md`；妈妈善食主题读 `../pregnabite-writing/SKILL.md`。其他平台或主题引用实际存在的包/确认来源，不能套用妈妈善食规则。记录本次组合与实际来源。

通用封面模式先读取A/B完整分析并判断适配，只分别写首张内容页（成稿P02）；用户选定后沿用上一步所选对标，再完成该套剩余实际文字，不展开未选方案。对标结构封面模式沿用A/B全套文案要求；标题调用 `../title-writer/SKILL.md`，正文按三部分写作要求执行。每块及每页写完立即 critique，再写下一模块；整组另审信息推进、重复、图片与发布正文分工。评论挂件词和角度按 `writing-core` 处理，不让评论更改主线。

输出及审批执行 `../content-writer/references/brief-approval.md`：全量上图文字在飞书 Creative Brief 最后维护，Image Brief 逐页引用，用户批准后才交生成。两套内容验收引用 `../content-writer/references/production-review.md`，不复制规则。

## 逐页逐块对标模仿（严格执行）

漫画⑤必须执行[完整故事与漫画文案分别写作](../story-builder/references/comic-storyboard.md#完整故事与漫画文案分别写作2026-10-16用户确认)：故事底稿只是事件和因果输入，实际短框单独改编，并按长度、表述、信息量逐句对照漫画原句及画面；不能将故事原文拆框直接交付。完整逐句记录进入同一稿的制作备注及⑥三轮复核。

漫画故事先执行 [漫画分镜与制作交接](../story-builder/references/comic-storyboard.md)，读取主题包的漫画规律和对应整组原图。在既有逐页映射中记录规律ID、原页、获批分镜中的事件、旁白／对白分工和来源。漫画数量按本篇获批的页与格核对，不能将知识图文的食物／条目数直接变为故事格数；原图仅有图片文字时标“未提供独立正文”。真实事实不足不通过补对白、反转或新人物满足结构。

痛点页、场景插图与人物对白执行 [场景协议](../research-core/references/scene-contract.md)。写前读取Brief中触发时刻、动作、阻碍与来源，逐页核对文字和拟用画面是否增加了无依据的经历或效果；示例在实际上图文字中明确标识，不能只留在制作备注。插画可以示意动作，但不冒充真实截图或记录。场景必须影响本页答案，不以一张焦虑人物图代替问题说明；检查并入原有三轮复核。

### 写作前必须读取已存图片分析（严格执行）

本门槛适用于每篇图文及整组重写。先实际打开所选素材在飞书的完整单图与整组分析，读取每页信息作用、标题与正文关系、条目/食物/例子数量、解释深度、插图关系及跨页推进，并核对原图。仅有链接、素材摘要、记忆中的分析或旧稿不算已读取。

在本篇制作依据记录原分析链接、章节与修订号或读取日期，并将各页任务和数量引用到下方信息需求表；原分析仍只保存在素材库。完整且一致时直接复用；缺页、缺数量、仅有外形描述或与原图不符时，交 pattern-extractor 原位补齐后再读取，不在 writer 另建分析副本。不能跳过本门槛先选食物、拟数量承诺或写图片文案。

### 先确定原图信息需求，再查证写作（严格执行）

每页文案送审前执行 `../image-generator/references/acceptance.md` 的“对标页的文本量与主次核对”，逐区对照实际文字和容量。通用写作的解释要求通过图文整体完成，不要求在原图短标签后追加理由。

先从当前稿读取已确认的 `cover_mode`。`benchmark`（用户明确不使用通用封面）时，对标原帖第一页无论是纯标题还是有实质内容，都写作成稿P01；原帖P02至末页按原序对应成稿P02至末页，总页数等于所选对标页数，不能因原帖P01只有标题而跳过或另加通用封面。A/B候选分别按各自完整原图规划，封面候选获批并展示后由用户选定唯一整组，剩余页只写所选方案。`brand` 时才执行以下首页去重规则，再统计最终页数；此为用户已确认的规则，不要求每篇重新批准同一判断：
- 原首页只有标题、装饰或重复的封面介绍，没有独立知识时，由本账号封面替代，原首页不写、不生成、不再作为内页。阅读承诺由本账号封面兑现。
- 原首页有清单、表格、具体建议、例子或实质图文信息时，保留其信息任务与数量，按对标模式生成一张内页，放在本账号封面之后；不能因它被称为封面就跳过。
- 生成前在 Image Brief 明列“原页→信息作用→替代/保留→输出页码”，封面单列且只有一张；总页数=1张本账号封面+保留的内容页数。例：原6页中首页纯标题，输出1+5=6页；原6页首页含7项提醒，输出1+6=7页。后续逐页数量检查针对保留内容页，不再机械要求最终总页数等于对标总页数。确有无法判明的首页信息，先核对原图分析。

1. 先引用整组原图及 `pattern-extractor` 分析，列出“原页 → 阅读任务 → 信息关系 → 独立条目/食物/例子数量 → 原图实际承载的理由、解释、吃法与插图（不存在的区块不增设）”。这份信息需求表必须先于本篇具体选材与文案；旧稿食物和现有事实池只是可检索材料，不能预先锁死内容范围。
2. 按上述首页规则明确封面与保留内容页；保留内容页逐页继承条目数量、页面任务与前后推进，数量与信息关系同时验收。例如对标为“首页7项谨慎选择＋后5页每页2项推荐”，使用独立品牌封面时输出1张封面＋6张内容页，保住7项提醒和10项推荐；不能把提醒页降成导航或用现有少量内容限制选材。此例只说明对应方法，不固定其他对标的数量。
3. 按每个信息位置需要回答的问题检索本篇主题知识，核验适用条件，再选具体食物/例子并重新写作。来源支持类别原则、具体菜品为基于原则设计的示例时，在制作依据如实区分；不能把设计示例称为指南原文推荐。不同条目须有独立选择价值，不拆近义项凑数，不用机械轮换同几种食材代替补充研究。
4. 信息不足时继续补研究；确实无法找到足够可靠内容，报告具体缺项，保持未通过状态。不得擅自减项减页、改变页面功能或编造结论。需要调整已选对标结构时，先给出具体冲突及调整方案，获得用户明确确认后实施；笼统认可对标不等于认可未展示的结构改动。
5. 写完逐页回对：页数与每页有效条目数、提醒/推荐等任务、内部关系、解释密度、插图指向、依据和独立信息量全部吻合才可送审。只符合数量、只模仿图文位置或逐句表达通顺均不足以放行。用户要求重写时，退回信息需求表和选材，重做受影响内容及标题承诺，不能把旧文案换排版交付。

读取整组原图、实际文字及已存 `pattern-extractor` 分析，核对一致后引用分析，不重复建档。先理解整组回答什么、怎样展开，再逐页逐块建立“原页/原句位置 → 信息作用与关系 → 表达手法 → 本篇实际文字/插图任务 → 事实依据”。

逐句借鉴语气、句式、长短句、重点位置和解释/举例方式；逐块核对标题为何统领这些文字，块之间是并列、因果、步骤、比较还是总结。表格说明每列含义、行内对应与跨行比较，总结如何降低理解或记忆负担；插图说明是在示例、对照还是补充说明。整组检查前后页如何推进，同一句大字报按整体语义分析，不机械数行和文本框。

写后将原图对应内容和本篇完整文案并排审：有无只复制外形而丢失解释关系、有无多块同义重复、有无例子或插图失去作用、有无变成通用口号。逐句执行 `writing-core` 四项检查，逐标题调用 `title-writer`；A/B 各自通过才送审。原帖内容不自动成为本篇事实；结构和表达用本篇知识重新实现。

图片模仿范围遵循用户已确认的结构学习要求；颜色、字体、插画等视觉风格采用账号已确认方案，不自动整套照搬新对标。统一视觉风格尚未制定时，在 Image Brief 将拟用视觉与结构分别列出供既有审批，不自行当作长期规则。
