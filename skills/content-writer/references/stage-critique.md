# 逐环节 critique

## 执行方式

每个环节先明确预期，再完成产物、自检、修改和复查。制作备注按“预期 → 实际表达 → 差距 → 已落实修改 → 复查结果”记录简短、可定位的证据。没有发现问题时写清核对对象与依据，不虚构缺点，也不只写“通过”。存在可修正的明显问题就先修正，不能只向用户解释问题后交差。

先检查内容是否兑现核心承诺，再检查格式与视觉。检查只在当前已授权阶段进行，不为完成全表提前生成正文或越过用户选择节点。用户局部反馈后，保留已认可内容，重查受影响的上下游；更改主题、标题承诺或例子时，同步核对图片规划、提示词、成图和正文，未重新生成的图片不得标为已同步。

## 先否决不合格方案，再检查细节

Critique首先检查是否违反用户已确认要求，不能仅修文字、算术、配色和尺寸，然后把整个方案写成通过。逐项记录实际证据；任一前置要求不满足，当前环节判为不通过，退回对应环节修改。下游细节合格不能抵消上游选错对标。

图片生成前首先核对：候选笔记标题与链接、原帖封面原图及其在整组中的位置、整组图片顺序、本文封面与该封面的对应关系。必须实际查看原帖封面；本篇封面只能参考该帖封面，不能抽第3、4张等内页充当封面，不能把同一篇的两个内页当成两组候选。采集顺序或封面身份不明时先核实。封面不适配则换整组，不能用内页绕过。

007反例：以B57第3、4张内页生成两个封面，即使标题保留“孕期补钙”、菜品完整、尺寸正确，也必须在对标选择环节否决。修改“这一餐”等措辞不构成该方案通过critique的证据。

## 审查顺序与硬性退回条件

每次重新审查实际产物，不沿用自己的“已通过”结论。按下列顺序串行执行；前一项不通过，先修正再继续。审查不是给现有方案找理由。

1. **核对任务账本及其来源。** 从用户原话、已确认选择和完整对标建立应交付清单，记录原话或可定位来源、当前授权阶段、主题、标题、模板、候选数量、成稿页码及每页任务。区分“用户确认”“AI拟定”“事实待核验”；用户选封面不等于认可AI未展示的页数或删减。先审清单是否忠实覆盖要求，再核对产物，不能只拿自己缩减后的计划证明完成。
2. **先审整组，再审单页。** 将原帖全部页码、各页任务、条目数量，与本篇全部页面并列。逐项说明保留、转化或省略的理由，以及省略后问题由哪里回答。不得只说“主题更聚焦”便把多页压成封面加一张补充页，也不机械沿用原帖页数。
3. **核实新增信息。** 对实际文案执行下方“逐句信息价值与凑页硬检查”，为每页列出具体新答案、读者可做的选择、与前页的重合项。仅复述封面菜名、替换同义词或加通用配餐，不能自动认定整组内容充分。逐页做删除测试：删掉该页到底少了哪个独立答案？没有损失就合并或删除，不为保留页数另找内容；整组遗漏仍需补齐，不以去重为由减少必要内容。无效警示、自我免责或助手回答口吻未清除，文案阶段即退回，禁止进入图片生成。
4. **用真实例子验收承诺。** 正文进入交付检查时，必须定位实际产品承接原文并执行下方独立 critique；缺少承接或主旨不适配即退回，后台备注、图片品牌名及其他项目合格不能抵消。 从成稿里指出能完成标题承诺的完整例子；例如三餐搭配应有可区分的早餐与正餐安排，营养科普应有食材选择理由，不能只有菜名数量。图片、正文各自覆盖什么明确记录；尚未写出的正文不得当作已交付答案，也不能用“以后正文解释”掩盖图片本身承诺未兑现。
5. **反向审事实、提示词与成品。** 先找可能不成立的建议、缺失条件、文案和图像不一致，再检查模板结构、细节、字体和尺寸。只做文字/尺寸校验不能判内容通过。每项结论指向可见原文、页格位置或实际图像；没有查看的项目写未检查，禁止默认通过。
6. **整改后重审依赖项。** 按“问题及证据 → 严重程度 → 实际改动 → 重查结果”记录。违反用户要求、主题缺失、关键事实错误、内容不足是阻断项，必须清零才交付；明确用户已接受的取舍与真正未解决项。修改页数或内容路径后重审整组、标题兑现和提示词，不只复查改过的字。

每轮审查结论仅用“通过／退回修改／待核验”，并注明适用阶段。不能用总分、美观程度、已有生成成本或保留进度抵消阻断项。交付前只看本次有效产物再走一遍任务账本，防止旧计划、失效图片、未选模板混入成稿。

## 标题独立 critique

每条标题单独审查。选源时记录不同的主对标原句和主规律，满足候选来源要求即可；生成后不横向比较三条，不做组合差异、去主题词同构测试或优劣排名。审查对象只有当前标题及其对应原句。先遮住制作备注，从首次看到标题的目标读者视角读一遍，再回到原句检查模仿有没有损失。

1. **代入感。** 哪几个字让读者认出自己的处境、正在做的事或担心？具体指出落点；只有“孕妈”身份标签，其他内容与她的困境无关，不能判通过。
2. **情绪与好奇。** 哪个实际词句使人警觉、焦虑被接住、意外或想追问？读完自然会产生什么疑问？写出由标题本身引出的具体问题，不能从正文或备注倒填。“一定注意”需有明确对象；“别焦虑”需有具体困境与可信帮助；感叹号或情绪词的存在不是效果证据。
3. **点击后的内容预期。** 读者能否知道点开会看到哪一种相关答案、解释或可用内容？该内容能否回应刚调起的情绪与疑问？只制造警觉却不给内容方向，或只写“避坑表／讲清”而看不出与自己有什么关系，退回。可以给出部分结论，只要它仍牵引读者了解原因、影响或做法；不强制每个标题留悬念。
4. **点击理由。** 把代入、情绪/好奇与内容预期连起来：为什么这位读者此刻值得点开？说明实际句子怎样形成这条联系，不只说“警示型所以吸引人”“有数字所以有收益”。需要靠制作备注讲解标题好处才能成立，判为退回。
5. **忠实模仿与力度损失。** 与自己的完整原标题并排看：点名读者、强表达、句式、节奏、问题推进与收益是否保住？逐处指出被削弱、变抽象或变拗口的措辞。不能因为追求原创主动改掉原句有效写法；也不能因有相同强词就判成功。事实有误时纠正具体断言，保留适用的语气与推进，不把整句磨成平淡目录。

以上各项均须落到可见词句，再核对事实、数量兑现、字数及违禁词。每条自己的问题必须清零，其他候选质量不参与放行。编辑推断不能写成已实测用户会点击，更不能保证传播效果。

### 修改后重新审查，直到达标

每次按“原标题与本稿实际表达→问题及可能的读者反应→具体改动→重新完整审读→复查结论”循环。修订后重走全部五项，检查是否出现新问题，不能只检查刚换过的词。没有固定修改轮数，不因已经改到第二版就停止；主观满意必须由具体通过依据支撑。仍有明显问题继续改，源句不合适就重选对标，不把待修标题交用户质检。制作备注只留当前有效候选的依据与简短修订结论，不堆版本。

### 用本次失误回放检查

- “两瓶别挤在一顿”：与“一定注意”和具体同服判断相比，“挤”弱化且模糊了动作关系。即使备注写成警示型，仍应在情绪/好奇与力度损失处退回；检查读者还会关心哪个值得展开的问题，不能替它编造点击动机。
- “4种补剂同服避坑表，孕妈别焦虑”：数字和“焦虑”不自动有效；必须证明具体困境、情绪承接和内容收益连得起来。无法从句子本身建立联系，在点击预期与点击理由处退回。
- “你真会吃吗？DHA也要错开？”：两个疑问句不自动增强张力；回到对应原句的行为反问与学习收获，检查本稿是否明确建立了阅读预期，不能靠自我检验型标签放行。
- 第一版存在问题，改第二版后仅写“已增强情绪，通过”：缺少对新标题的完整复审，退回循环；不能把完成修改当作完成验收。

## 明确答案与认知负担检查

内容规划、上图文案、生成提示词、实际成图和正文交付均执行本检查；必要条件的存在与推卸回答责任分别判断，不能只统计“如果”的出现次数。

1. **指出实际答案。** 从读者可见内容中直接摘出对象、动作、安排与理由。标题问“怎么吃、什么时候吃”，回答却只有“按要求安排、视情况而定”，判为退回。
2. **列出剩余任务。** 读者看完仍需自行查说明、确定规则、换算或重排时间吗？作者能够查清的内容必须先查清并写出结果；制作备注有答案但图片没有，图片仍不通过。
3. **消除嵌套条件。** “如果说明要求错开，就按标明时间安排”没有新增答案，退回核验具体产品后重写。产品不同就按产品或类别分别给结论，前提与动作相邻；不把多个分支堆在一张图，也不为删除条件词而省略适用范围。
4. **核对确定性的依据。** 明确的时间、间隔、成分数字必须对应已读来源与具体对象；把某款说明套给全部产品，或虚构统一剂量，即使措辞干脆也退回。无法核实就补查或缩小承诺，不能用“自行查阅”结束本篇核心回答。
5. **读者复述测试。** 遮住制作备注，只读这一页或这一段，能否一句话说出自己已经获得哪个答案、下一步是什么、为何这样做？仍只会复述“我要再去查、再自己判断”，说明尚未完成知识转化。必要个体评估须明确评估事项与下一步，不能伪装成适用于所有人的现成安排。

012反馈回放：用户指出“如果要求错开……”“根据写明的时间安排”等表达。这些句子应在第1—3项被拦截：没有兑现具体安排，且把资料核验与安排工作留给读者。将其机械改为“全部固定错开”仍应被第4项拦截。正确修复是在写前核实本篇具体对象，再直接交付适用结论。用户报告数据为历史新低，不将未经核验的数据或单一归因写成事实。

## 整组完成判定：先锁定范围，再核对实物

### 逐句信息价值与凑页硬检查

本检查在实际文案写完、生成提示词定稿、成图后分别执行，正文同样适用。先审文案再出图，不能把“做了图片”当成文案已通过。遮住制作备注，逐句读面向读者的原文：

1. **信息在哪里？** 摘出本句实际提供的知识、因果、做法或有必要的阅读引导；“作者没保证什么”“这不是推荐”“不必理会传言”不算答案。无法指出对本篇读者的用途，删除或改写。
2. **读者学会什么、怎样做？** 从本页原文指出能直接复述的结论和行动。只有“不要……”“不代表……”或抽象提醒，仍需读者自行推理下一步，判退回；有事实依据的提醒必须接上具体对象和做法。
3. **是否混入求稳、规避责任的口吻？** 逐句检索“不代表、不意味着、仅供参考、不作为、不用为、不要、不能”等表达，结合上下文判断其用途；只解释作者立场的删除，有价值的事实限制转为“明确对象/条件＋明确答案”。不机械禁用否定词，也不能通过换近义词躲过检查，更不能省略决定安全性和准确性的条件。
4. **这一页有必要独立存在吗？** 摘出本页相对前页新增的具体答案；删掉后承诺仍完整、没有知识或行动损失，就合并或删除。三点承诺不等于三张或七张图片；原帖页数、自拟计划、生成成本均不构成保留理由。合并后另审可读性，避免一页承担过多信息。
5. **复查实际改稿。** 修改后重读完整文案并重走以上四项；通过后才能生成。成图逐字回看，模型额外添加的免责声明同样退回。制作备注写“问题原句→无效之处→删除/替换后的实际句子→读者能获得的答案”，不能只写“有信息量、已检查、通过”。

013失误回放：原审查虽然核对了7页数量、标签数字和间隔，却让“这张表……不表示这些组合都要吃”“不用为这条传言，再多安排一个服用时段”进入成图。这些句子应在第1—3项退回，不能以科学审慎或字数不多放行；一页只留下否定传言而无直接安排时，第4项也应退回。实际修改须交付经核实的具体做法或将有效信息并入日程，不能只删句后留一张空泛页面。

规则回放的放行标准：四页已充分回答全部承诺、字号可读，应交付四页；七页中两页只剩重复提醒，应减页而非补套话；“具体类别的铁剂与钙剂间隔至少2小时”有对象和动作，可继续核实依据；“不用再多安排时段”没有给出具体安排，退回。这里是流程验收用例，不能冒充当前013已完成改图。

### 逐图读者收获与问题解决硬检查

选题确认后、逐页文案进入提示词前、每张实际成图后、整组交付前，四次执行；封面以人群、困境和阅读承诺检查，内页按以下问题逐一审。遮住正文、制作备注及设计意图，只看读者实际能看到的文字和图像：

1. **这张图具体回答什么？** 用一句话写出本页对应的当下问题，以及画面给出的答案。仅重复主题、换一幅插画或列出没有判断方法的食物名称，退回。
2. **读者能获得什么新信息？** 摘出至少一个准确、有来源的知识点、适用范围、选择标准、可复用方法或完整例子，并指出它相对前页新增在哪里。图中事实错误、数值无依据、建议与场景不连贯，即使文字少且好看也退回。
3. **读者看完能照着做什么？** 写出具体对象、动作、条件或示例；检查读者是否还需自行查证、计算或猜测“加什么、加多少、什么时候加”。作者能够完成的核验和换算须先完成。需个体化判断时明确判断依据及下一步，不制造统一答案。
4. **它帮助解决本篇核心问题吗？** 把本页答案接回标题承诺和读者眼前的选择。信息虽正确但只是旁支科普、产品口号或重复前页，退回或移出本组；产品横幅不能替代本页知识与方法。
5. **删掉这一页会失去什么？** 指出独立知识或行动的损失；若无损失，合并、删除或重写，并复查整组是否仍覆盖承诺。单页用不同措辞反复说同一件事，不因页数达到计划而通过。

记录格式为“页码及实际可见原文／画面 → 本页问题 → 新知识或示例及依据 → 读者动作 → 与核心问题的关系 → 与相邻页重合及删除测试 → 结论与实际修改”。只填主题名、任务名、主观观感或勾选通过无效。生成后对模型实际加入、改错或漏掉的内容重新逐项审查，不能拿提示词代表成图。017反例：阶段表给出数字后，整组没有把增量换成可执行的食物示例；餐次页与家庭备餐页重复；喝汤页“把食材也盛上”没有解释已吃了什么、缺什么、是否仍需加餐。这些应在第2、3、5项退回，先修内容逻辑再生成。体重线图须标明适用人群、坐标含义与数据性质；产品横幅只说已核实能力，不承诺长胎不长肉等效果。

### 内容差异检查（选模板及生成前）

将本篇与内容主对标、图片模板原帖并列检查：具体菜品或例子、配料组合、排列顺序、解释重点和读者行动。只换名称、少量克数、同义词或健康标签，不算实质差异；记录本篇新增或重组的具体价值，不能以图片重新生成代替内容创作。无需为了不同而强行使用罕见食材、编造功效，常见食材与基础知识可以重合。

当同一套模板使内容和原帖过于接近，退回内容与模板适配阶段；用户允许时可重新匹配整组模板。换模板也须重新检查内容，不能把同一份高度重合的食谱换外观就放行。选定后仍按整组参考、封面对封面、内页对对应内页执行。008反例：沿用B05六款组合及顺序，只更改少数配料和名称，虽视觉与事实检查通过，内容差异检查仍应退回。

“整组”包含所选封面及应交付清单中的全部有效内页。它同时要求内容覆盖完整、产物齐全且用户能实际取得；三项分别验收。读完对标7页、写完7页提示词、调用7次生成工具，都不等于交付7张图片。

- **形成基准。** 正式生成前，依据用户要求与整组映射写明总页数、逐页编号和信息任务。用户明确要求几页时遵守该数量；未指定时，依据完整对标及本篇内容形成有依据的清单，不默认机械同页数，也不能默认为封面加一页。原帖某页不沿用，必须说明其功能如何被有效转化、合并，或为什么不属于本篇内容边界。
- **防止验收标准随产物缩水。** 开始生成后保留这份基准。失败、耗时、只生成了部分、想保留进度均不能成为删除待交付页的理由。内容审查确需调整页数时，记录变更前后页码及任务、具体依据、被合并内容的实际落点，并重新审整组。触及用户明确数量、内容承诺或已认可设计才需用户决定；一般实现选择自行完成，不增设常规审批。事后改成“两页计划”不能消除第一次漏交整组的事实。
- **逐项核实状态。** 每个应交付项分别记录“文案已定、已生成、已看图验收、已归档、已写入指定交付位置”的实际状态。保存当前有效文件路径、对应原图、验收证据及飞书图片块/附件位置；缺失状态保留待完成。旧图、未选候选、重复文件和失败输出不能充当缺页。
- **检查全部工具结果。** 批量生成须逐一处理成功、失败及未返回项；不能只展示成功结果或忽略Promise.allSettled中的rejected。错误项继续排查、补生成与验收；真实阻碍无法排除时只报告已完成项、未完成项和具体阻碍，不宣称整组完成。
- **单独执行交付核对。** 在最终回复前重新打开应交付清单，对照实际文件及指定交付位置，逐页确认存在、顺序、内容身份、当前有效状态和可访问性。写入飞书后回读图片块、顺序与显示尺寸；上传成功响应不替代回读。总数相等仍需逐项身份匹配，防止重复图片顶替缺页。
- **清理失效版本后才放行。** 按production-review的成稿清理流程，检查本地与飞书均只留当前有效图文；删除已被替代的生成图片、废弃方案及无用Markdown/临时文件。标记“废弃”却继续保留仍判不通过。核验删旧后最终页数和正文不变；不误删源素材或用户手改稿。

制作备注使用一张清单贯穿全程：

| 交付项/页码 | 要求来源及确认状态 | 本页任务/对标原图 | 文案/生成/验收状态 | 有效文件及交付位置 | 缺项与处理 |
| --- | --- | --- | --- | --- | --- |

只有“要求覆盖通过＋逐项产物齐全＋实际交付核对通过＋本阶段阻断项为零”同时成立，才可使用“整组完成”。已有授权时持续补齐，不把“要不要继续剩下的”变成新的审批点。用户本轮仅要求复查流程时，范围是流程修正，不据此自动改图或写正文。

### 用反例检查这套审查是否有效

修改critique规则后，至少回放本次真实失误，指出在哪一条应被拦下；规则文件校验及同步只证明部署，不证明行为正确。以下为判定用例，不代表已实际生成或执行工具测试：

| 场景 | 正确判定 |
| --- | --- |
| 用户要求整组，AI自行缩成两张再报2/2完成 | 先退回范围来源检查；自拟分母不能证明满足用户要求 |
| 应交付6页，仅生成2页，但两页美观且文字正确 | 产物齐全检查失败，继续补齐4页 |
| 生成6次，1次失败或未返回 | 失败项未完成，不得按调用次数计数 |
| 有6个文件，其中1张旧图、1张重复，实际缺两页 | 逐页身份匹配失败，文件数量不能替代清单 |
| 各图本地合格，飞书漏一页或显示尺寸错误 | 交付核对失败，修正后回读 |
| 原帖7页，本篇有依据转为4页，所有承诺有实际落点 | 先审范围变更依据及内容覆盖，再审4页实物；不凭4/4或页数增加自动通过 |

对007第一次交付的复查结论：范围基准与整组内容均未充分验证，就用自己制定的两页方案作验收分母；随后以局部文字和尺寸检查替代整组完成检查。应在第一项退回，不能靠后来补图追认第一次通过。新增检查须能在用户指出之前拦住同类遗漏。

007反例：B07原组7页，本文只交封面及重复16道菜的配餐页。即使每格有字、两张图片尺寸正确，也不足以证明内容已充分展开。应在整组覆盖和新增信息检查阶段发现问题；用户追问后不能仅道歉和承诺，须修改规则并实际完成已授权内容。

## 产品承接独立 critique

先核对主Skill“人群问题与新功能探索”中的模式。现有功能承接篇的产品承接是正文必交付内容。内容方案阶段先明确问题、相关能力、证据与位置；正文获授权后检查实际句子，不提前越过停顿点。不得自行以弱关联或避免广告感免检。

新需求/新功能验证篇使用已确认的研究模式：核对实际方法/方案能否回答问题、概念是否标注未上线、功能状态是否诚实、验证信号与观察方式是否明确。缺少现有产品功能不判失败，伪造现成功能或只给空洞概念仍退回。本节下方五项和010反例适用于现有功能承接篇，不能强制新需求篇植入无关能力。

逐项记录“本篇要求 → 实际承接原文及位置 → 产品证据 → 差距与修改 → 复查结论”，以下五项全部通过才可放行：

1. **存在性。** 正文有读者可见的产品名称、形态及具体用途。只有制作备注、图片 logo、产品名或评论互动不算承接；缺失直接退回修改。
2. **主题价值。** 承接同一个核心问题，明确产品帮助读者完成什么。PregnaBite 饮食搭配篇着重营养搭配，连接食物营养分工与产品按孕周营养需要／缺口推荐食谱的已证实能力；仅“下一餐吃什么”“更多菜谱”“省事”不足以通过该主题。将主题换成另一篇后仍完全通用的句子须改到本篇具体用途。
3. **功能证据。** 每项能力对应本次读取的账号产品资料、用户确认或实际产品证据，记录路径／URL与支持内容。不臆造按钮、字段、计算精度、整餐达标、症状改善或使用效果；证据缺失先核实，未核实标为待核验，不能标通过。
4. **衔接与表达。** 连读承接前一段、产品段和互动段：内容先回答本篇问题，产品段自然延续其营养决策，再进入评论与标签。避免功能堆砌、广告口号、无依据的个人体验和站外导流；品牌功能存在但转去无关卖点仍退回。

5. **独立写法对标。** 定位用户指定或已认可成稿中的产品承接原文，连读其前后段，与本篇逐句对照场景入口、产品出场、用途落点、句长、分行及口吻。产品说明书式长句、抽象词堆叠，不能因存在品牌、营养关键词和真实功能就放行。当前PregnaBite优先读取001“最终手改版（已发布）”：其“如果觉得每天想食谱很麻烦→小程序妈妈善食→记录每日营养缺口”可用于本篇推进和节奏参考；不照搬效果保证，不把特定格式推广为所有主题必用。没有实际原文和本篇对应证据时，此项待核验。

删除测试：移除产品段后，应在存在性检查被拦下。替换测试：仅放产品名、或换成泛泛的“推荐午晚餐”，应在主题价值／具体用途检查被拦下。改稿后回读实际交付文档，不能只检验待写文本或凭检查表已填写判通过。

| 实际问题或检查用例 | 应拦截的位置与结论 |

| 补“想把午晚餐也搭起来……推荐全天食谱”，重点仍是有菜可选 | 营养搭配主题价值不通过，须写明营养需要如何进入推荐依据 |

| 品牌、营养关键词和功能齐全，但缺少单独写法对标，读起来像说明书 | 独立写法对标不通过，读取001实际原文并改写，不能继续因前四项齐全放行 |
| 明确承接、营养主旨、能力依据、衔接与独立写法对标均有证据 | 五项分别核对后通过；不据此替代整篇其余检查 |

## 各环节的检查点

| 环节 | 必须回答的问题与通过依据 |
| --- | --- |
| 调研与痛点判断 | 原帖、评论究竟说了什么？哪些是证据，哪些是创作判断？实际困境是否被偷换，资料是否足以支持当前方向？保留原话与可定位来源。 |
| 初稿 Creative Brief | 是否在初稿最前面明确 Target、Pain、Search intent、Angle、Template、Evidence、Product presence、Tone reference、Forbidden？每项来自用户确认或实际调研吗？Evidence 的数量与具体交付是否对应，Tone reference 是否写明借鉴动作？Product presence 是否说清“从什么问题转入产品、展示什么真实能力、放在什么位置、读者为什么需要”，并实际进入页面和正文任务？只填数字、强弱等级、“自然植入”或空泛标签时退回修改。 |
| 主题与内容构思 | 写给谁、解决什么具体选择、读完获得什么？对标展开和用户确认如何落到本篇？内容是否过薄或散到多个无关问题？ |
| 对标选择 | 是否先定主题再评估整组结构能否承载内容，而非按暂拟标题或相同营养素筛选？是否读完正文与整组图片，并写出各页如何转化为本篇内容？是否实际查看原帖封面？内页冒充封面直接不通过；仅因原帖没有相同主题而排除，也应退回重评。 |
| 标题 | 是否从具体对标原句出发模仿，选源分别对应不同主对标与主规律？生成后每条独立执行代入感、情绪/好奇、点击内容预期、点击理由和原句力度损失检查；每次改写重新走完整审查，直到问题清零。取消三条横向比较。核对数量与事实承诺，不让标题反向限制有效内容。 |
| 整组图片规划 | 每页、每格的实际文字和例子是否写全？每页新增什么价值？餐食、营养解释与方法是否有机结合，完整例子是否足以让读者学会？页数不由标题中的步骤数机械决定。 |
| 封面文案与提示词 | 从已确认主题到上图文字再到完整提示词，是否丢了人群、核心问题或收益？仅看封面能否理解这篇与自己有什么关系？按下节独立验收后才生成。 |
| 实际成图及每轮修改 | 隐去发布标题与正文，只看图片，实际传达的主题是否符合预期？再对照原图检查版式、细节、缩略图可读性与尺寸。提示词写对不代表成图通过。 |
| 开头 | 是否本次实际读取开头规律及原文？前两三句的具体问题、答案方向和继续阅读的收益是什么？与参考开场相比，是否铺垫过长、先说无法判断、迟迟不给信息？保留用户认可的导读。 |
| 正文风格 | 原段与本稿对应段是否并排核对了语气、句式、长短句节奏、段落推进及收尾？指出具体落点和仍有的偏差。内容不同不构成不适配；只对齐话题、字数、小标题、Emoji或添加感叹号不能判通过。若去掉主题名词后仍是每篇惯用的同一套写法，应退回重写。不得事后挂来源名，或用事实正确抵消风格未落实。 |
| 正文篇幅 | 是否实测正文主对标与本稿字数，统计范围是否一致？两者是否保持相近篇幅？上下约100字的差异可以接受，不硬卡区间或百分比；300字与1000字这种明显差距须调整。明显超长先压缩信息重复再交付，不只报告没有固定上限。 |
| 信息优先级与用户洞察 | 内容、句式、顺序是否分别审查？已读洞察的证据等级是否明确？餐名／段首是否尽早交付用户关心的营养关系或选择理由？若重要信息靠后，检查是否真有铺垫、指代、条件或因果依赖；无依赖则前移，有依赖连必要前提一并调整。不能照搬对标顺序，也不能把前提丢掉。010以用户最终稿前置三类吸收关系、后补类别和做法作为复查实例。 |
| 正文写作与改稿 | 每段的信息点、核心意思、读者能学会的选择分别是什么？一分钟扫读能抓住什么？营养科普是否被做菜流水账和泛泛建议挤掉？提纲是否保留，各模块是否推进信息？关键词等形式是否按需选择、被误当必用句式？保留必要解释与已认可表述，只去掉重复意思。 |
| 产品承接 | 按上方独立 critique 逐项定位正文原句、主题用途和能力证据；缺失承接或泛化为更多菜谱即退回，不能以自然适配为由省略。 |
| 整篇交付 | 标题、封面、内页与正文是否兑现同一承诺？来源、事实、写作原则及违禁词是否已核对？从首次看到笔记的读者角度连读，不能依赖制作备注才能看懂。 |
| 用户修改与复盘 | 用户实际采用、删除、改写了什么？哪些是本篇修正，哪些是明确要求沉淀的规则？落实到对应规则并同步运行副本。发布数据在用户提供或已授权采集范围内分析；已授权定时采集按 review 的采集方案交接，不把更新规则当成调度已启动。 |

## 封面生成前：审完整提示词

读取pattern-extractor的封面机制参考：悬念/好奇/反差与实用结果、情绪共鸣均可采用。明确具体未知点、用户为什么想知道、在哪里揭晓；不要求封面披露全部答案，不用空泛神秘词替代主题。查看实际成图时同时验证该机制是否成立，不能只检查“有用”和字大。

在制作备注写清三项：本篇不可丢失的核心语义、封面第一眼应传达的内容、提示词中的实际上图原文。逐项比对，不能用读者尚未看到的正文补足封面缺失的主题。

例如本篇承诺为“孕期控糖｜3步算清一餐碳水”，只写“3步算碳水”会丢失孕期控糖的关键语境。应在选定原图已有的文字区域和层级中保留“孕期控糖”及方法收益。这是语义完整性检查，不规定所有封面都用相同句式、行数或步骤数。

对标设计仍按用户选择锁定。不能为忠实版式擅自删掉主题，也不能借补主题添加原图没有的小字、标签或装饰。优先在既有文字位重组表达；确实容纳不了时，明确容量冲突，按已有授权调整，涉及改动用户锁定设计才请用户决定。

每轮新增或修改提示词都重新检查完整文本，特别检查“只保留某句话”“不要出现某词”等限制是否误删核心语义。提示词内部冲突、主旨缺失或整组实际内容尚不充分时，不进入生成。

## 生成后：审实际读者所见

实际看图，先用一句话概括图片传达的内容，再与预期比较。完整尺寸检查内容和细节，缩略图检查人群、主题和阅读收益是否鲜明；两种视图都要检查。随后按 [图文生产与交付验收](production-review.md) 核对逐格餐具、视角、食物、文字层级等细节。

发现主题弱、关键信息缺失或生成偏差，修正对应内容或提示词并重新生成、重新看图。记录本轮实际修正及仍存局限；被否定图片退出有效候选。用户要看封面时，交付已经完成上述自检的封面，不能把用户当第一轮质检。
