# 图文生产与交付验收

本文件与 [逐环节 critique](stage-critique.md) 配套执行。整组规划完成、每轮提示词定稿、每轮实际成图均分别自检；生成前先确认主题语义完整，生成后先检查实际阅读含义，再检查下列设计细节。不能仅在正文完成后统一检查。

## 先筛适配，再生成候选

先通读当前初稿的主对标内容映射与已确认主题，核对内容承诺、信息推进、具体例子及证据状态；再读“评论调研校验记录”，确定需要补充回答的问题。建立“本篇核心承诺 → 标题承诺 → 各页图片的回答 → 正文各段的回答”映射，再选图片对标，并标明评论副问题的回应位置；缺失证据不得写成已完成校验。正文和图片共同兑现核心承诺，不能让单条评论自动决定全文，也不能为了列全菜品或填满版式偏离主线。已明确选择评论建立场景时忠实回应，用户明确保留现有图片时不擅改，适配局限记录在制作依据中。

先明确主题、核心问题与内容边界，再选择整组图片模板。模板主要按能否承载本篇内容判断，检查页面功能、信息容量、食物/例子数量与解释空间；不要求原帖主题、营养素或具体问题完全相同。菜品合集与餐次搭配均可转化为补钙内容，先做实际映射再判断，不以原帖没有补钙主线直接排除。

先评估两篇整组模板候选，分别写出“原帖封面与整组结构 → 本篇内容如何组织 → 实际菜品和营养解释 → 容量与图文分工”。可调整本篇表达方式，不能为填格而凑内容。模板与内容方向确定后，必须实际读取标题规律库，再按内容拟3个标题供选择；标题选定后才生成封面候选。不足两篇时继续查找已授权素材，仍不足则展示合格方案并说明具体容量缺口，不凑数。

每个候选单位是一篇完整笔记。本篇封面必须对应候选笔记的原帖封面，不能从其内页挑一张充当封面，也不能将同一笔记的两张内页包装成两个候选。记录并实际查看原帖封面、整组顺序与来源；采集顺序不明先核实。原帖封面不能承载本篇主题时，淘汰该整组，不以“内页容量合适”放行。

用户选定封面，即确定该封面所属笔记为整组图片主对标。后续图片的内容组织、分组、例子展开、页面顺序、信息层级及视觉均参考该篇；逐页映射只在这篇笔记的整组图片内进行，禁止每张另找一篇或混搭未选中的候选。其他资料可补充事实与具体内容，不承担另一套图片模板。用本篇有依据的内容改写，不照搬原文或未经核验的结论。

B类04的长文使用限制仍适用。B06《整个孕期补剂总结｜新手妈妈看这一篇就够了》（6a2384e00000000007010ade）已由用户删除并永久排除，历史缓存与草稿引用也不得重新作为对标。

## 设计锁定与细节检查（生成前后都必须执行）

用户选定封面及所属主对标后，封面和内页均保持各自对应原图的设计。内容按本篇主题与已确认标题替换，设计不得自行发挥；除非用户明确要求，不增减单页网格或食物/插图数量、不改布局、不增加原图没有的文字层级和装饰。整组页数遵守用户明确要求及生成前的交付清单，调整按stage-critique的范围变更规则执行；不能把单页设计锁定与整组页数混为一谈。事实核查用于纠正内容，不构成重做设计的理由。

逐页建立“原图可见细节 → 本图对应要求 → 实际成图核验”的记录；拼图逐格记录，不能只概括整张风格。以下项目必须实际看图确认，不存在的项目注明无，不得臆造：

| 检查项 | 必须对应的细节 |
| --- | --- |
| 构图与容量 | 网格行列、格数、边界与分隔、各主体位置和大小、图文比例、裁切与留白 |
| 文字 | 实际文字块数量、行数、上下位置与间距、字号层级、字体粗细与倾斜、描边、底色或刷痕；原图无菜名标签、说明、脚注或角标时不得新增 |
| 餐具与道具 | 勺子、筷子、碗盘各自的种类、材质、颜色、形状、大小、可见部分、伸入方向与夹起/舀起动作；不同餐具不能被统一替换 |
| 视角与层次 | 俯拍或斜拍、取景距离、前景主体与背景的位置、遮挡、景深和虚实、碗沿露出程度；保留原图各格差异 |
| 食物与光色 | 本篇菜品对应的位置、分量呈现、形态与纹理、光照方向、高光、明暗和色彩差异；图中食物必须与后续内容对应 |
| 装饰 | 原图实际存在的刷痕、线条等的位置、面积与作用；不得添加原图没有的元素 |

将这些具体要求和对应原图一起交给生成工具，不只写“模仿对标风格”。生成后对原图和实际成图并排检查完整尺寸与缩略图；逐格核对餐具、视角和层次，再核对文字行数与位置。发现额外小字、同款餐具铺满、视角被统一或结构改变时，直接修正并更新提示词，不以提示词已写要求或整体相似作为通过依据。

005/B25的已确认纠错示例：原图三列三行、只有上下分开的两行大字，不得改成六格或添加菜名、底部说明；瓷勺、银色金属勺、金色金属勺、筷子及其方向和远近逐格对应。此例用于说明如何忠实参考；其他对标按各自实际设计执行，不一律套九宫格或两行字。

## 选定模板后再校准信息量

### 内容完成后主动 critique，再进入出图

每次完成内容规划、图片生成或正文改稿，都由 AI 主动执行“检查具体问题 → 修改 → 复查”，不等用户指出，不以道歉或列出下一步代替修改。制作备注只记录实际发现的问题、落实到哪一格/哪一段的修改和复查结果，不虚构缺点或机械凑检查条数。

生成封面前，先写完整组每一格的实际内容、对应原图、该格新增的阅读价值及图文分工。内页只写“讲计算”“讲搭配”等任务名、实际菜品和例子仍未准备好时，不能先生成封面交差。先检查内容是否足够且有用，再检查排版、尺寸与美观。

标题中的“3步”等数量是必须兑现的承诺，不是全文只能容纳三条提示的上限。食谱与方法结合的主题，应提供足够具体的餐食选择、相关营养解释和实际示范，让步骤在餐食例子中自然发生；不得把同一餐盘重复多个格子，分别贴“看标签、称重量、相加”等口号充数。已明确采用的评论可作为问题入口；用户允许扩展时，可增加服务同一问题的餐食与场景，但不能伪造为评论者原话或经历。

逐页检查：遮住菜名后是否仍有实质差别？每格是否增加一种有用选择或知识？读者能否沿完整例子实际完成标题承诺？数值是否有依据，算例是否从输入、单位、换算到结果完整？营养解释是否被流程口号挤掉？对标若用餐盘提供多样搭配，应保留这种内容价值；不只复制网格外形。解释可按对标容量放在正文，图文共同兑现承诺，但必须明确哪些信息只在正文，不能宣称图片已教会全部步骤。

发现内容单薄，先补相关素材、有效餐食和完整示范；发现重复，改成有不同用途的内容；发现数值缺证据，核实或明确改为假设算例。不能靠增加页数、小字、装饰或用户事后纠错弥补。被用户否定的图片退出有效候选；替代图交付验证后删除废弃生成文件及对应飞书图片块。问题只在当前制作备注简记，不保留废图作为问题记录。

每个候选生成封面前先做一次校准；用户选定后，对整组内容页再次校准。逐页记录：原图每区的任务、条目数、约字数/行数、例子或食物数、图文比例；本文对应区的实际文字与条目数。以原图容量规划本文有用的解释、例子、动作和必要条件，但不能为填满画面添加无关知识、重复内容或未经证实的结论。

信息多时先删重复，把补充解释放正文，保留选定原图的文字层级、网格与图片数量；信息少时不能自行删格、改图文比例或填入无关内容。整组仍不适配时明确说明具体内容缺口后再调整方案，不暗中改动已认可设计、不跨笔记另找模板，也不把封面版式重复铺满内页。不要通过极小字号、异常留白或自创布局勉强容纳。整组页数结合有效内容与主对标确定，不预设每篇8张；产品承接优先放正文，只有对应原图存在适合的区域或用户明确要求时才上图，不另加底部小字。

生成前须保存整组覆盖表：原帖每页任务 → 本篇对应页与具体条目 → 新增答案 → 重合信息 → 省略理由或正文分工。按[逐环节 critique](stage-critique.md)的硬性退回条件检查。不得将“16格都填了”“主题聚焦”“原图本来重复结构”作为内容充分的证据；结构可以重复，读者获得的答案须推进。原帖7页与本篇2页这样的显著收缩，必须核实是否遗漏核心问题和实际内容深度；有缺口就补内容，不先宣布整组完成。选择完成后删除未选生成方案与失效计划，只维护当前有效图片清单；来源保留链接，不复制未选整组到交付目录。

## 成稿清理与唯一版本验收

1. 先列当前有效页码、文件、飞书图片块与正文位置；读取现有文档，识别用户手改内容。新版本实际存在、内容合格且写入后回读成功，才删除被替代文件，不能把未完成生成当替代物。
2. 清理范围包括本篇工作目录内的废弃生成图、旧正文、未选方案、无用Markdown副本、临时XML/JSON快照和一次性脚本；本篇明确可定位的工具生成废图副本也清理。不得跨任务清空共享缓存；不得删除原素材库或仍在使用的成图。
3. 飞书同页删除旧图片块、过时制作方案和废弃候选说明，只保留一套当前图文。当前来源、事实边界及必要验收信息集中到制作备注；不复制完整过程日志，不为清理重写用户认可正文。
4. 删除前核对文件绝对路径、当前有效白名单与引用；删除后重新盘点文件及飞书，核对页数、顺序、身份、显示尺寸、正文内容不变。仍留有被替代版本即判交付不通过，先清理再回复。
5. 008回放：封面名称放大后，旧字号封面和更早B05生成封面均应删除；最终封面加6内页共7张。另存的正文Markdown、多个计划Markdown及反复抓取的XML不能作为额外交付留下。不得用“已标为废弃”代替删除。

## 每页交付

正式生成前建立并保留[整组交付清单](stage-critique.md#整组完成判定先锁定范围再核对实物)，每页更新实际状态。完成全部单页验收后，另做一次整组交付核对：用户要求 → 清单 → 当前有效文件 → 指定交付位置逐项一致。批量工具失败或缺图必须处理，不以成功返回的部分图代替整组，不因局部检查通过提前结束任务。

- 上图原文：所有实际显示的文字，逐区写全，不混入“核对、不得出现”等制作指令。
- 制作说明：选定主对标的笔记标题、具体原图路径/编号、该页在整组中的阅读任务、内容改写、排版与风格、区域容量，以及上表逐区域/逐格的细节对应记录。所有页面须归属同一主对标。
- 实际提示词：保留传给 imagegen/image2 的完整文本、参考图片路径和尺寸要求；修改图片后同步当前提示词。
- 验收：主对标是否与选定封面一致、后续内容是否参考该篇的整组推进、是否跨笔记拼模板、是否偏离本篇问题，以及实际尺寸、完整非透明背景、文字无截断。逐项确认设计未擅改、无额外小字、餐具与视角等细节已落到实际成图；保留具体核验记录。统一配色不能代替整组内容连贯，提示词存在不等于生成图已通过。

## 文案与承诺验收

正文结构按“场景和问题 → 答案方向 → 一句具体导读 → 分项解答”验收；答案方向可与开头解释合并，不强制独立总体方案句。导读明确点名后文分别解决的困难，小标题及内容按同一顺序兑现；保留这种帮助读者理解内容的导读，删除空泛预告与后台创作说明。不强制固定三个模块或三餐结构。

检查疏密与扫读：按选定正文对标的语气、句式和段落组织承载本篇内容，使用具体菜品组合、简短小标题、关键句或必要的重点标记帮助扫读，段落自然说明做法、理由及替换条件，扫读能抓住安排，关键词行仅为可选。细读能理解营养理由与选择方法，不能每篇固定成“餐名＋关键词＋营养解释”。内容可以不同，写作方式须有可定位的原段与本稿对应证据；按stage-critique中的正文风格项独立验收。导读用自然语句概括方案，不把多个带引号的完整问题拼成目录句；不能把“易读”误解为全文越短越好。

正文每个模块均须有独立来源映射：对标原文/图片文字及具体位置 → 借鉴写法 → 对应规律 → 本文具体落点 → 支持事实的已读资料。开头、总结、CTA同样检查。只列素材编号或一组资料链接不算逐项对应；原创组织如实标注，不虚构参考原文。

逐项对照标题承诺和真实提问，定位图片页及正文答案。例如“按阶段整理”须清楚交付各阶段的重点与行动，不能只按营养素列名单；“看是否缺乏”如果未给出可用判断信息，就是尚未回答的选择问题，应补足有依据的答案或收窄承诺。

逐段逐页问：这部分如何兑现本篇核心承诺，读者因此知道怎么选、怎么做了吗？选用的评论副问题是否在合适位置得到回应？只有主题关键词相同、菜品介绍完整或对标设计相似不算通过。正文可选择必要的图片例子，不要求按图片顺序复述全部菜品；图片先行的生产顺序不改变用户痛点优先的内容逻辑。

最后检查实际交付：用户能采取什么动作、为何这样做、哪些问题仍留给读者；有无重复空话；原文映射是否完整；提示词是否已存；产品承接是否自然适配且有证据（弱关联允许省略）、评论/点赞钩子、5—8个标签是否存在；当前只有一版AI初稿。以可定位的文本和图片作为通过依据，不以章节齐全或校验脚本通过代替质量判断。
