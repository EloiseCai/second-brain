# 图文生产与交付验收

## 先筛适配，再生成候选

先明确本篇问题、答案和有效信息量，再筛原图的主题、阅读方式、模块数、文字量、图片数与字段关系。只有适配的原图才能进入两套封面候选；不足两套时继续查找已授权范围内的素材，仍不足则展示已合格方案并说明缺口，不用不适配素材凑数。B类04的长文使用限制仍适用。

## 选定模板后再校准信息量

每个候选生成封面前先做一次校准；用户选定后，对整组内容页再次校准。逐页记录：原图每区的任务、条目数、约字数/行数、例子或食物数、图文比例；本文对应区的实际文字与条目数。以原图容量规划本文有用的解释、例子、动作和必要条件，但不能为填满画面添加无关知识、重复内容或未经证实的结论。

信息少时合并页面或重新匹配低密度原图；信息多时删重复、按独立问题分配页面或匹配容量更大的原图。不要通过极小字号、异常留白或自创布局勉强容纳。页数由有效内容和对标容量共同决定，不预设每篇8张；产品承接可放最后一张内容图底部。

## 每页交付

- 上图原文：所有实际显示的文字，逐区写全，不混入“核对、不得出现”等制作指令。
- 制作说明：具体原图路径/编号、排版与风格、区域容量和本文适配方式。
- 实际提示词：保留传给 imagegen/image2 的完整文本、参考图片路径和尺寸要求；修改图片后同步当前提示词。
- 验收：实际尺寸、完整非透明背景、文字无截断、原图层级是否复现、密度是否匹配、整组风格是否统一。提示词存在不等于生成图已通过。

## 文案与承诺验收

正文每个模块均须有独立来源映射：对标原文/图片文字及具体位置 → 借鉴写法 → 对应规律 → 本文具体落点 → 支持事实的已读资料。开头、总结、CTA同样检查。只列B06或一组资料链接不算逐项对应；原创组织如实标注，不虚构参考原文。

逐项对照标题承诺和真实提问，定位图片页及正文答案。例如“按阶段整理”须清楚交付各阶段的重点与行动，不能只按营养素列名单；“看是否缺乏”如果未给出可用判断信息，就是尚未回答的选择问题，应补足有依据的答案或收窄承诺。

最后检查实际交付：用户能采取什么动作、为何这样做、哪些问题仍留给读者；有无重复空话；原文映射是否完整；提示词是否已存；产品承接、评论/点赞钩子、5—8个标签是否存在；当前只有一版AI初稿。以可定位的文本和图片作为通过依据，不以章节齐全或校验脚本通过代替质量判断。
