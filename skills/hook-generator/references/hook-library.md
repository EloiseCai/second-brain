# 钩子原话与规律库

## 存储与职责

当前主题的 `03_内容规律/钩子原话与规律` 是钩子引用入口，由主题包 hook_library 绑定。通用 Skill 维护方法，主题文档保存实际原句、读者语境与用法。pattern-extractor 在对标分析时增量记录；hook-generator 在策划后读取选用。独立历史扫描也可执行本协议，不需要重跑选题或全库营养核验。

保留既有标题、开头规律与单篇原文。钩子库收录必要原句及其吸引机制，通过来源链接关联原资料；不复制整篇文章、完整图片分析或另一套同义规律。相同原句与同一来源只存一次，不同来源的变体分别保留。

## 扫描与记录

1. **整篇阅读是完整分析的前置要求。**以一篇对标为分析单位，读取发布标题、完整正文（含中段、结尾）、整组图片及其已有分析；视频还读取可用的实际脚本与画面资料。标题汇总只能定位素材，不能作为整篇钩子提取的唯一输入。标明原话所在段/页，图片原话来自原图或可核对转写，已有图片分析以分析引用标记。材料缺失时具体标出该篇缺哪部分，不能以借鉴规划填成已完成的整篇分析。
2. 保留完整自然语义原句与关键短语，原有措辞、标点和顺序不改写。区分完整标题、正文开头和短摘；模型改写另列“本篇用法”。用户提供示例直接记录原话和用户提供这一来源，未给链接不虚构。
3. 用连贯自然语言写清“读者已有的关切/认知 → 看到的具体信息 → 产生的期待 → 愿意继续看的理由 → 后续兑现”。以原句的实际措辞解释组合如何起作用，不止做类别命名。写法分析可以合理推理，不能自动变成用户访谈、普遍痛点或实测效果。
4. 每条保留稳定ID、完整原句、关键表达、来源链接/素材路径及位置、读者语境、具体期待、表达组合的作用、画面/声音配合、原文实际兑现、迁移要点与关联规律。用几段自然语言覆盖，不强迫做宽表。未读取的画面与正文集中标明材料范围；所提画面和兑现方法明确为借鉴规划，不填入实际观察。数据有则记录实际指标；没有不补效果。
5. 钩子可叠加：例如“孕中期”定位阶段，“不费妈/快手”突出省时省力，“8道/做法”给内容预期。不要拆完后只留下“数字＋人群”而丢掉具体卖点。
6. 单条即可保存和参考；同一种机制至少两条独立素材支持时再归候选规律，用户提出的方向单独标明。分析完成在原文档结构内更新并回读。新用户洞察按 audience-report 统一写入关口处理；纯表达机制不冒充用户洞察。

## 整篇钩子与各载体的关系（严格执行）

先记录同篇的标题、正文与图片具体钩子，再写整体阅读路径。正文和图片既能兑现前面的承诺，也可能独立建立新的期待：正文中的具体体验、意外信息、口感描述、被理解的感受、操作诀窍、故事转折、结果展示等，都要按其实际作用识别。不能预先把标题等同于钩子、正文和图片仅等同于解释。

整篇记录至少覆盖已存在的载体：标题原话；正文中实际起吸引作用的完整语义原句及段落位置；图片的实际文字、成品/比较/操作等视觉吸引点及页码；这些信息如何互补、加强、转移或延续期待。按原资料顺序说明第一处吸引、随后的新期待与收获、最终行动。不存在明显钩子的位置可以如实说明，不强制每段每页制造一个。

保留同篇稳定主ID，按标题/正文/图片标出子位置供调用。已有标题卡扩充为整篇卡；只有片段或缺链接的示例单独标为片段线索，不与完成整篇读取的记录混淆。正文原话与图中文字分别引用，不互相代替；整组分析可引用已有分析，并明确本轮实际看图范围。

跨篇规律要比较完整关系，区分标题吸引、正文自身钩子、图片自身钩子及多载体配合，避免新增材料后仍只按标题类别分组。写作时选择整篇机制及需要的实际原句/图片位置，交给对应writer，不能只取标题然后自行想象正文与画面。

## 写作时怎么用

先读本题具体人群、场景、承诺和已有信息，再搜索库中相关原句。按“用户为什么会停下”选用，不按主题词机械匹配；重点比较利益、好奇、信任线索和本篇能否兑现。原句与规律同时读，必要时回到具体来源核对上下文。

可直接保留贴合的常用短语，如“快手”“一锅出”“直接抄”；完整标题按本篇内容组织。涉及专业身份、机构来源、独家关系、个人经历或确定效果时使用实际材料，不把“月子中心不外传”自动当作本账号真实来源。保留信任与好奇的表达价值，不一律磨成平淡的“食谱推荐”。

记录选用理由与实际采用表达，给标题、封面、图片和正文标注各自落点；不强迫每处重复同一句钩子。对标结构、图片信息量与本篇事实继续按各模块原规则执行。修改后复核具体吸引点是否被抽象化、弱化或与内容脱节。

库缺对应钩子时，从本篇已选对标增量提取并写入同一文档，再继续写作，不凭空编造“对标原话”。不为补钩子库启动无关的大规模采集。

## 深度分析方法

解释完整的吸引关系。例如机构名可能同时带入专业服务、付费体验、特定人群的联想；接上内部经验和具体做法后，读者才形成“将专业服务的一部分带回日常使用”的期待。不能把组合拆碎后只留下“权威、数字、好奇”。具体联想依目标人群及证据解释，不视为所有用户共同心理。

使用删除/替换比较：选择承载主要作用的词句或画面，说明删掉、换成普通表达后，哪一种期待减弱、哪一种增强。此为分析工具，不是用户测试。比较数量依实际内容，不设额外配额。例如“快手”强调时间，“一锅出”强调操作组织，“不费妈”还可能传达对做饭者精力的照顾，应分别检查原文具体兑现了什么。

同时分析三种作用：首次停留/点击的理由、继续阅读的理由、获得收获后的行动理由。按实际材料选用；CTA、互动邀请的写作职责继续归原模块，不与吸引点击混为同一指标。实用内容可以直接展示结果并通过新信息持续留人，故事可以通过人物选择和后果推进；不强制延迟答案、每页设悬念或套固定反转句式。

画面、屏幕文字、口播共同传达同一个可理解的期待；画面可以展示成果、操作便利或关键证据。缺实际画面时不能由标题推定布局。迁移保持已确认的品牌风格和对标信息结构；钩子规划不能擅自改变页数、食品数量或已批准的内容。

## 写作交接与 critique（严格执行）

交接写入内容包本分支：钩子ID/原位链接、完整参考原句与读取位置、读者语境及依据、具体期待、关键表达/画面如何共同起作用、本篇采用表达及载体位置、第一处实际收获、后续阅读理由、承诺对应的内容章节/图片页、缺口。原文观察与本篇规划各写清楚；共用来源引用，不复制整篇。title-writer、image-copy-writer、body-writer实际回读后落实。

逐项检查并修正：

1. 是否实际读取同篇标题、完整正文、整组图片资料，正文与图片的独立钩子是否被提取，缺失的载体是否明确？能否说清具体哪类用户为什么在意，语境有依据，未擅自添加新的经历或困扰？
2. 能否用一句自然语言表达用户期待的具体收获，而非“激发好奇”等空标签？
3. 删除/替换比较能否指出关键作用，改写是否保住最有吸引力的部分？
4. 实际画面与文字是否共同加强同一期待，单看首屏能否理解？未读画面是否如实保留缺口？
5. 后文何处首次交付收获，下一段/页还有什么新信息值得继续看，是否把期待全部拖到最后？
6. 换到本篇主题后，来源、数字、角色、结果和信息量是否成立，是否忠实于同一选题主线？

检查记录包含具体问题、修订与复查依据；有缺项先补齐/修正再放行。源材料不足的条目可留库供检索，不能将拟议画面或兑现方案标成已验证的完整对标分析。跨篇重复只能支持候选机制，实际效果另引review的观察和条件。
