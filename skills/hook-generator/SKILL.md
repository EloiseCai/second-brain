# 钩子生成器

读取内容包统一Creative Brief、当前类型/平台策划、真实洞察与具体对标，组合 writing-core、平台和主题规则。把已有开头规律作为钩子的写法来源，引用原文档，不复制规律库；开头是钩子的一个落点。后续将开头研究纳入本模块，现有文档链接先保留。

围绕前3秒注意力这个设计目标，规划读者最先看到什么、具体场景为何相关、哪个问题/信息差/画面让人停下、继续看的预期，以及后文如何兑现。3秒是创作检查视角，不冒充实际留存测试或保证。

记录标题、封面首屏、正文开头、漫画首格或视频开场分别承担的钩子作用，按本轮实际载体选用。由 title-writer 等在正式写作阶段落实成品；不在这里重复生成整套标题或文案。

critique核对：场景有来源，承诺具体且可兑现，钩子与主线一致，没有捏造恐惧/经历/效果，首次看到能理解。写入内容包的本分支钩子章节，回读后交 story-builder / 平台writer。场景细化影响钩子时回到本模块校准。

本轮只固定职责、位置和交接；数量、候选形式、评分及详细写法之后细调，不自行新增硬参数。
