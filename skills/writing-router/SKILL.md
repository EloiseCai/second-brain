# 写作入口

先读 [配置与交接](references/handoff.md)，依据语义与已有任务识别需求，不用单个词硬匹配账号。

1. 新任务确定平台、内容类型、载体、账号/主题及选题来源；续做先通读飞书当前稿与执行状态。用户已说清的字段直接沿用，仅对有歧义的组合确认一次。
2. 加载 `../writing-core/SKILL.md`、当前平台包及当前主题资料。小红书用 `../xiaohongshu-writing/SKILL.md`；公众号用 `../wechat-writing/SKILL.md`；仅妈妈善食用 `../pregnabite-writing/SKILL.md`。账号不明不能默认妈妈善食。
3. 小红书知识型图文执行 `../content-writer/SKILL.md` 的 A—N 流程；公众号知识型长文执行 `../wechat-writing/SKILL.md`。其他组合缺执行包时先细调该分支，不宣称已支持。
4. 事实、对标分析、洞察、产品能力保留原位置引用，写作与 critique 使用同一套要求。图文衍生长文先复核可复用证据，只研究新平台结构、证据变化和内容缺口，不重做已确认选题。
5. 平台切换不继承另一平台的字数、标签数、Emoji、封面比例或页数。账号表达偏好继续使用；旧要求范围不清时列为待核对，不擅自推广或取消。
6. 每模块执行通用、平台、主题三部分 critique。状态写入飞书；“继续”只推进记录中的下一步，不代替新功能说法、改题或方案选择的批准。

规则可迁移；飞书权限、登录态、工具与账号素材需接通。新主题先绑定自己的资料，缺素材进入研究，缺权限报告具体缺口。相同规则保证相同要求和检查点，不承诺逐字相同。未跑完实稿的分支标为试行。
