# 当前可用分支与启动提示

所有人使用同一套 Skill，不区分员工版与维护版。每次进入 writing-router 或恢复任务，读取本目录 routes.json 的当前分支状态。

首次引入或开始新任务，列出 status=ready 的平台与形式，并说明其余分支仍在施工，然后询问“是否开始？”。用户已经明确要求开始则直接执行；仅安装或引入不自动研究、生成。续做读取已记录的阶段，不重复问启动问题。

当前提示：“目前可以生成小红书图文和公众号长文，其他分支还在完善。是否开始？”实际提示随 routes.json 更新，不长期硬编码两个平台。ready 表示当前可用，不表示所有细调待办已完成。

按用户选择调用已就绪分支；施工分支如实说明进度，可继续细调，不冒充可完整生产。初始化的平台菜单与策划使用同一份状态，不另设员工白名单、锁定版本或角色权限。原有 DIY、独立调研与维护能力保留。

维护者确认新分支 ready 后，更新 routes.json 对应状态与实际入口，随同一套 Skill 同步发布。其他电脑拉取并运行安装同步后即使用新状态，无需解锁或换一种包；本地文件不会凭空自动更新。续做保留既有批准项与实际 next_step。
