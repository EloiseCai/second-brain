# 六维分析与生成：通用标准

六维为触发处境（生活场景）S、人群身份I、年龄／阶段G、核心痛点P、当下情绪E、行动障碍B。由research-core维护唯一字段标准，audience-report执行；主题包只提供领域取值、材料与位置。具体任务是行首摘要，来源是证据列，两者不计入六维。

## 字段写作标准（严格执行）

| 字段 | 必须回答与写法 | 自检 |
| --- | --- | --- |
| 具体任务（摘要） | 用自然语言写“想完成什么＋具体对象或待判断的选择”，有动作和结果。例如“想确认喜欢的羊血能不能作为补铁食物”。 | 单看这一句能否知道她想做什么？不能写“羊血具体追问”“阶段营养导航”等索引词。 |
| 触发处境 | 写此刻发生什么、正在做什么，什么事情让问题出现。用完整句子保留时间、地点、对象等已有关键细节。 | “看清单后”要说清看什么清单、为什么产生这个问题；不凭空增加场景。 |
| 人群身份 | 用人群称谓或短标签，如初孕者、准爸爸、学生、上班族、家庭做饭者。 | 禁用“读者”“评论者”“某作者经历”替代身份；材料身份放来源。无真实身份时注明“目标人群：…（内容推断）”，不冒充发言者身份。 |
| 年龄／阶段 | 当前所处的人生或主题阶段；年龄仅在已有证据且有用时记录。具体取值由主题包定义。 | 不填“按来源”“各篇不同”等流程词；不能把来源编号、任务、心情当阶段。未披露细阶段时写已知大阶段。 |
| 核心痛点 | 用一到两句说明她在意什么、担心什么、想得到什么却没有把握；从原话和处境合理推理深层关切，并以“可能／从…看”标明。 | “生怕少吃一点亏待宝宝”归这里；不要只列营养名称或写一个泛泛问题，不新增无依据的疾病、经历或目标。 |
| 当下情绪 | 只写简洁感受词，如担心、慌乱、困惑、纠结、期待、厌倦。原话明确则直接写；合理推断写“可能…”。 | 关注点、偏好、愿望与推理长段落不塞进此栏；不能把每条都推成焦虑。 |
| 行动障碍 | 解释为什么想做却做不到、做不好或迟迟无法决定，具体到缺少哪条判断信息、方法、条件或身体限制。 | 不重复任务或痛点；不能只写“搭配”“选择”“口感”。推断的阻碍说明“可能”；不知道原因就写清尚缺哪部分信息。 |
| 来源 | 原话、上下文、来源类型、原始链接／可定位ID；保留作者或评论身份及明确阶段细节。 | 原话与分析分开，不把生成句加引号。 |

## 执行顺序

1. 读取现有洞察及原始表达，保留ID、来源、已有用户纠正；先确定本条究竟在回应哪个具体问题。
2. 把用户正在面对的事情写成触发处境，再写一句具体任务。将索引短语展开成人能直接理解的句子。
3. 提取人群标签与年龄／阶段；概括性内容只标适用目标人群，不把它当已采访的个人。
4. 分析“想要的结果→在意或担心的结果”，写进核心痛点；再提炼简短情绪词。由处境推理可以补全分析，不能补造身份、孕周或亲历事实。
5. 单独解释行动障碍，核对它是否真正阻止该任务完成；一条只回应同一情境，多来源细节不能拼成一个人。
6. 逐行逐字段critique并修正：任务可理解；场景具体；身份是人群标签；阶段是状态；痛点讲透关切；情绪仅感受；障碍解释原因；原话和来源可追溯。任何一项不合格修正该行后复查，不用全表一句“通过”代替。
7. 写入后回读，核对行数、来源与关键原话、用户补充仍保留，表头准确，关联问题没有漂移。将具体场景交给下游，不能只交分类名。

## 六维生成选项与研究假设

从已有材料提炼维度选项，缺少的选项可作为明确标注的研究假设。选择兼容身份与阶段，从具体任务组合场景、痛点、情绪与障碍；不穷举或拼接不同人的经历。用真实搜索、访谈、笔记及评论验证和反证，保留日期、原话与上下文。按任务＋触发场景＋实质障碍去重；只有身份或阶段真正改变问题和解法才拆分，换词或情绪不另造问题。

关键词及自然语言问题卡执行 [洞察记录协议](../../audience-report/references/insight-recording.md)。通用方法不设置母婴阶段或PB编号。
