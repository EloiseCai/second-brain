# 第一人称故事长文与制作交接

适用于主题包已确认的真实当事人视角整理。妈妈善食从用户洞察回溯同一位孕妈的原始记录，与漫画共用事实；本协议细化既有S1—S5，不设固定字数、段数或额外审批。长文作为独立故事稿维护，不用漫画的发布配文代替。

## 写前分清经历来源与写法来源

经历来源回答“实际发生了什么”，沿用内容包的原记录、身份、事实顺序与缺口。语言对标回答“怎样组织和表达”，由body-writer按本篇平台读取完整正文及分析。两者分别标明；语言对标中的经历、家庭关系、情绪、产品和结局不能自动进入本篇事实。

漫画对标只有图片文字、没有独立正文时，可参考事件推进，但不能声称已经具备长文语言对标。按已有正文选源流程定向补齐或明确缺口，不把分镜对白拼成长文。故事主线和已知终点先确定，写法适配不能反过来要求补造事实。

## 叙述身份与可写范围

成品在开篇清楚标明根据真实记录整理及当事人视角，具体措辞按主题包和来源确定。“我”始终指原经历人物；编辑补充切换为明确的编辑说明，不在同一个“我”里混入账号作者或研究者的知识。

| 原始材料 | 长文处理 |
| --- | --- |
| 当事人写出的动作、处境与后续 | 保持原意，用连贯的第一人称叙述组织；具体细节仍可回查 |
| 当事人明确表达的情绪或想法 | 可以准确转述，不能擅自加重、扩展动机或替其总结人生认识 |
| 当事人记下的对白 | 引号用于可核对的原话；改写为间接转述时保留说话者与原意 |
| 只有动作，没有心理或对白 | 写已知动作，不填“我心里想”“他一定是担心”等推测 |
| 别人的想法、病因、改善原因 | 不因采用第一人称就获得事实资格；区分当事人判断与独立查证结论 |
| 记录没有后续 | 停在已知状态；不写成最终解决、释然或获得疗效 |

## 从事实主线写成连续段落

先用已有钩子和真实事件确定切入点，让读者理解“我当时在做什么，哪里卡住了”。相关背景放在理解动作所需的位置；不要求从怀孕之初顺叙，也不添加背景设定来制造现场感。

沿行动与反馈展开：这一步做了什么，实际遇到了什么，原记录接着发生了什么。转场用来源支持的时间或关系；时间不明就不新增“第二天”“一周后”等精确说法。可以重排讲述顺序，但须让读者辨认回忆与当前事件，不能把先后写成因果。

长文利用句段承接讲清漫画不便展开的必要背景和真实想法；漫画的服饰、房间布置、镜头或夸张表情属于视觉设计时，不能反向成为文字中的真实经历。每段围绕主线提供动作、信息或理解，删去仅重复上一段的情绪和结论，不靠扩写心理凑长度。

结尾落在记录已有的选择、变化或仍未解决的问题。是否有感悟取决于原记录，不固定升华或成功结局。读者所得可来自理解具体困境；需要知识解释时以编辑身份独立呈现并核验，不让孕妈突然替编辑讲出未曾记录的专业结论。

产品按本篇独立文字稿Brief中的开关与product-amplify执行，不继承漫画选择。故事展开与自然承接执行[故事展开方法](story-development.md)。原人物没有使用记录时，以面向读者的建议承接，不写“后来我用了……”；编辑推荐与当事人行为保持可辨认。

## 交接与复核

在内容包长文分支引用：叙述身份、共用事实记录、开场及切入理由、拟用段落顺序、已知结尾、语言对标和缺口。正式writer输出完整文章；平台未确定时保留该缺口，不因称为长文就默认公众号。

制作备注沿用body-writer逐句映射，同时区分每句的经历事实、写法借鉴与编辑补充；读者正文保留自然表达，来源编号留在制作备注。初写与改稿执行既有三轮复核，覆盖全文而非只审开头。

复核重点：离开漫画能否看懂事件；“我”有没有换人；心理、对白及具体时间是否有据；是否为套对标补出行为；编辑知识是否混为亲历；结尾是否超出已知后续。与漫画核对人物、触发事件、行为、结果和身份说明，允许详略不同。任一版事实更正后回查另一版受影响内容。

长文方案、完整草稿、复核通过、平台交付分别按内容包现有状态记录；只有提纲或漫画配文时不算长文完成。规则已细化不等于实际成稿已验证。
