# 封面生成

每次续做先执行 `../content-writer/references/resume-contract.md`，回读飞书执行状态及实际材料；封面形式与A/B方案身份分开，沿用已完成研究，按当前节点补齐具体依赖。封面调用生成工具前必须运行其中的交接检查脚本，通过后才执行实际图片生成。

本 Skill 负责经批准的通用品牌封面，或用户要求的A/B对标结构封面的生产，不重新决定选题或擅改已批文案。

规划、提示词与实图验收统一执行 `../image-generator/references/acceptance.md`；公众号读取 `../wechat-writer/SKILL.md` 并按正文后的图片阶段执行。品牌一致性与切入角度须分别有实际图像依据，不能以其中一项通过代替另一项。

封面的间距规划及实图验收引用 `../image-generator/SKILL.md` 的“通用图片留白与间距”，与内页执行同一要求，不重复维护另一套间距规则。

执行前读取通用 `../writing-core/SKILL.md`、当前平台包（小红书为 `../xiaohongshu-writing/SKILL.md`）与已确认主题包（妈妈善食为 `../pregnabite-writing/SKILL.md`）。三部分按实际来源组合，主题变化替换主题包。

## 统一封面标准（严格执行）

从主题包读取账号当前已确认的飞书封面规范及实际标准图，不能仅凭本会话摘要或候选图生成。规范中的固定区块、字体、颜色、强调形式、装饰、图片处理与品牌页脚逐项进入提示词；本篇标题、副标题、标签、主题装饰和图片对象作为变量。具体品牌细节只维护在飞书，不复制到通用 Skill。A/B 内容方案也沿用同一账号视觉标准。

本轮产物指定为通用品牌形式时，封面视觉与区块按账号已确认模板；执行 `../image-copy-writer/SKILL.md` 的首页去重规则：纯标题对标首页由本账号封面替代，含实质信息的首页转为内页。读取 Brief 的原页到输出页映射，仅生成一张本方案封面，不把被替代的原封面再生成一次。内页仍按已批逐页分析执行。用户局部修改只调整指定部分及必要关联，不重新设计整体风格。

本轮用户明确要求对标结构封面时，读取对应A/B原帖首页的信息结构及整体文本推进，采用获批主题文案与账号配色；不把通用品牌的固定区块强加到对标布局。该形式仍归属对应内容方案，不另算一篇对标。

实图 critique 在原有内容检查之外，逐项对照飞书规范与标准图，记录各固定区块在成图中的实际表现；整图及手机缩略图检查可读性。遗漏品牌行、改变高亮形式、字体/配色/图片蒙版漂移时修复再放行。候选留档不覆盖当前生效标准。

输入必须包含获批的对应方案/页码、已存飞书单图/整组分析的链接与版本、实际原图、Image Brief、Creative Brief 末尾获批文字、用户确认记录及账号已确认视觉要求。逐项执行 `../content-writer/references/brief-approval.md` 的审批和 `../content-writer/references/production-review.md` 的生产与交付规则。旧设计条款与用户最新统一风格要求冲突时，以当前用户已确认风格为准；尚未制定的品牌风格不能声称已锁定。

实际生成使用 `imagegen` Skill 和工具；每张提示词定稿后 critique，生成后查看实际图像、逐字核对获批文案，再按 `stage-critique.md`（位于 content-writer/references）验收内容、细节与整组关系。未通过修复再继续下一张，不能拿提示词正确替代成图检查。

通用封面模式执行 `../content-writer/references/production-review.md` 的“通用封面下的A/B内页选择”：cover-generator制作通用封面，image-generator在整组选择前仅生成A/B各自已批第二页比较样张，合并展示供用户选定；其余内页只生成用户明确选择的整组。通用封面通过不能代替整组对标选择。实际图片按原有主项目归档和飞书交付规则保存；不另建本地内容文档。

## 原图到实图的模仿验收（严格执行）

生成前实际读取所选飞书图片分析，并执行 `../image-copy-writer/SKILL.md` 的前置分析门槛与逐页逐块映射，区分需要借鉴的信息结构和本账号已批准的视觉风格。按每页实际区域将“原图信息作用 → 获批文本/插图关系 → 提示词落点”对应起来，不只写“参考某图”。

原分析、原图与获批文本的页面任务、关系或数量不一致且无明确结构变更批准时，退回修正映射与文案，不直接生成。

生成后同时看已存分析、原图、获批 Image Brief 和实际成图：逐区检查重点能否被看见、阅读顺序、表格对应、例子与解释、插图作用、总结功能以及实际文字是否一致。用整图和缩略图检查可读性；数量或配色接近不能替代信息关系正确。每页记录实际差距并修正、重新看图；封面合格不代表内页或另一候选合格。视觉按本篇已批方案验收，不将学习结构解释为自动照搬对标风格。
